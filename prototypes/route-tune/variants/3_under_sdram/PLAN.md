# 3_under_sdram 的计划

> 说明：这个文件是布置定下来以后补写的，不是先于走线落盘的。思路和“先算出来的四件事”是动手前的手算；表里的估计值也是那时算的，和实际的差别见最后一节。

思路：窄条（两颗芯片之间）里只过成束的线，不放蛇形、不打孔；要补的长度全部放到 SDRAM 封装下面的 L4 / L6。每根要补线的网络，在封装下面事先留一段自己的直线。

## 先算出来的四件事

1. **窗口由 NBL0 定。** A4 → K9 直连 24.0 mm，加两个 L1–L6 过孔 3.3 mm，一条 45° 斜线直穿最少也要约 27.9 mm。所以 SDCLK 要做到约 25.65，其余都要 ≥ 23.15。
2. **每根线都打 2 个孔。** 过孔高度按 DRC 的算法一个 1.39（到 L4）或 1.65（到 L6），两个就是 2.8 / 3.3 mm。短线（D8–D15、SDCLK）如果留在 L1 不打孔，要多补 3 mm；所以全部下内层，L1 只留出球和回球的短线。
3. **SDRAM 用到的球全在封装下部（J–R 行），上面 9 行这个原型里没有线。** 封装上半部下面的 L4 / L6 是空的，蛇形放这里。（真实板上这里还有地址线和高 16 位数据线的过孔，见 README 的“没做的”。）
4. **SDRAM 球只能从 L1 进。** 在 L4 上补完长度以后，要有一个过孔回到 L1。过孔放在封装中间没有球的那一条里（x 25.8–28.2），不占球区，L6 在左半边下面就完全没有过孔挡路。

## 分层

- **L4：D8–D15 和 SDCLK，9 行“梯子”。** 每根线在 SDRAM 左半边下面占一行东西向的直线，行尾在中间那一条打孔，L1 向南走一段、再沿球行之间的通道向西进球。过孔排成楼梯（每往下一行，过孔往东 0.33 mm），L1 的回程就一根套一根、不交叉。行的顺序 = MCU 出线从北到南的顺序 = SDRAM 通道从北到南的顺序，所以 L4 和 L1 都不交叉；换位表就是照这个顺序排出来的。
- **L6：D0–D7（除 D3）和两根 NBL。** NBL1、NBL0、D2 从 MCU 上边绕过右上角，各走一条斜线；D1、D0 从 MCU 右边斜到封装左半边下面的两行；D6、D7、D5、D4 从 MCU 下边向东直进（同 0_base）。
- **D3**（内圈球，只能从 L4 出）：从梯子上面过去，沿封装右侧下来。
- **L1：** 只有出球、回球。窄条里 L1 没有线，窄条里没有过孔。

## 蛇形尺寸怎么定（先算）

单边一块 n 个等高的弯，腿间距 p，摆幅 a：占直线 `2·p·n`，补 `n·(2a − 0.858·p)`。

- 一块从 x = 23.05 开始（整块都在封装外形里面），到这一行拐进过孔之前 0.35 mm 为止；这段长度除以 `2p` 取整就是 n。
- 摆幅 `a = (要补的 / n + 0.858·p) / 2`。
- 朝弯的那一侧，到邻线的中心距要 ≥ `a + 0.284`（线宽 0.09 + 蛇形间距 0.19）；行距按这个留。
- 目标：SDCLK 补到 25.65；低于 23.75 的数据线补到 23.75（比窗口下沿高 0.6）。差不到 1.2 mm 的，放 2 个最矮的带直腿的弯（0.405，补 1.1 mm）。

## 手写坐标的地方（线束工具表达不了的）

- 两颗芯片的出球线和回球线（工具不懂球之间哪条通道能走）。
- 梯子每一行的最后一小段 45°（0.2 mm）和 L1 回程：是按“过孔 x、通道 y、倒角”三个数用一个小函数生成的，不是逐点敲的。
- D3 整根（单独一根，不成束）。
- D4 末端一小段 45°。

其余（9 行梯子的斜线和行、NBL 三根、D1/D0、D6/D7/D5/D4）都是线束描述出来的。

## 计划和实际的差别

见 README.md 的“先算还是先量”。主要三处：过孔之间的距离我按铜到铜 0.09 算成了 0.2875，实际孔到别的铜要 0.2 mm（过孔间距至少 0.32）；SDCLK 那一行我原想双边蛇形，放不下，改成单边 2 个高弯；D3 原来走封装上沿外面，凸包大了 28 mm²，挪到上沿里面。

复查（2026-11-17）又改了一处：D2 斜线末端的小蛇形夹在两个过孔之间，去掉了；D2 和 D3 对调 SDRAM 的球，D2 末端向南多走 0.8 mm 进窗口。
