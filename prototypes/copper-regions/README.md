# 原型：铜皮区域（一次性，看完即弃）

对应 [原型：按草图用脚本生成电源层分块和外层局部铜皮，给用户看效果](https://github.com/immorcoding/PCB/issues/16)。只存在于分支 `prototype/copper-regions`，不合并。

**要回答的问题**：铜皮外形由人写成草图、脚本只负责检查和生成，这样出来的铜皮认不认可；和现成的铺铜工具比，用哪一个。

三种东西并排放在同一块占位板上：

| 方案 | 做法 | 目录 |
|---|---|---|
| A 草图 + 脚本 | `sketch.txt` 写外形，`sketch2zones.py` 检查后生成 KiCad 铺铜区 | `out/a_sketch/` |
| B 现成工具 | KiCadRoutingTools 0.24.0 的 `route_planes.py`：自动分割 L3、四层铺地 | `out/b_krt/` |
| A 的三个变体 | 块间缝 1.0 mm；插件焊盘也全连接；贴片焊盘也花焊盘 | `out/a_gap10/`、`out/a_solid/`、`out/a_thermal/` |

## 怎么看

- 双击 `compare.html`：← → 换方案，↑ ↓ 换视图，下面是同一张指标表。
- 在 KiCad 里打开 `out/<方案>/h7cu.kicad_pro`。板子已经由 `kicad-cli` 重新填充并保存；如果 KiCad 正开着旧文件，用"文件 → 还原"。
- 重建：`sh build.sh`（约两分钟；方案 B 需要主工作区的 `Tools/KiCadRoutingTools`）。

## 占位板不是真板

没有原理图，网络直接指定在焊盘上。**以下都是占位，没有核对过规格书**：

- SDRAM 的球号、codec 的脚号、LCD 排线、RJ45、microSD 的引脚定义；所有器件的位置和朝向。
- MCU、稳压器、PHY 的电源脚号取自 KiCad 符号库（`STM32H743IIKx`、`LMR51430`、`TPS62A02PDDC`、`TPS7A20xxxDBV`、`LAN8742A`）。
- MCU 的狗骨过孔：第 3、4 圈和中心 25 个球每球一个 0.30 / 0.15 过孔，外两圈只给地和 3.3 V 的球打孔；SDRAM 只给电源球打孔。没有信号走线，没有背面去耦电容。
- 没画的铜皮类网络：`SW_3V3`、`SW_BL`、`LED_A`、`VDDA_MCU`、`VDDA_PHY`、`+12V_F`（保险丝到 MOS，用一段线代替）。使能脚各自是单独的走线类网络。

## 结果（2026-11-16）

数字全部取自 `kicad-cli pcb drc --refill-zones --save-board` 填充并保存后的板文件（PWR-6），由 `measure.py` 算；图只作定性参考。

### 顺带发现的事

1. **规则区的间距规则会波及整板铺铜（已验证）。** 规格档 C 的写法 `A.intersectsArea('BGA_…')` 对铺铜区是按整个区判断的：一块铺铜只要盖到规则区，全板都按 0.09 mm 填充。原型里铺地到局部铜皮的间距实测 0.092（设的是 0.20），L3 两块之间 0.092（设的是 0.127）；规则加上 `A.Type != 'Zone' && B.Type != 'Zone'` 之后回到 0.201 和 0.128。正式板的规则文件要改。
2. **MCU 下方的电源面。** 第 3、4 圈每球一个过孔时，相邻过孔的避让圈连成墙，但 42 个 3.3 V 过孔仍然全部落在铜里（两版相同）。这是只有占位过孔、没有信号线和背面去耦时的结果，实板只会更差，规格档 C 里"球阵下的通孔对平面完整性的影响"这一项仍然没有答案。
3. **读回可行。** `zones2sketch.py` 把板上的铺铜区读回成草图文本，再生成一遍，12 块铺铜区的顶点数和面积完全一致（`out/a_sketch/sketch_readback.txt`）。
4. **仓库外没有别的现成工具。** 调研了 Novin3dp 的 Claude skill、几个 KiCad MCP 服务器、kipy、kicad-skip、ViaStitching 一类插件、KiKit、Freerouting：外形都要调用者自己给，没有一个会分割电源层或围着一组焊盘生成局部铜皮。KiCad 10 自己也没有"按网络生成平面"的功能。
5. **`measure.py` 的两个坑。** KiCad 存的填充是带切缝的（孔洞用零宽切缝连到外轮廓），直接收缩会沿切缝断开，要先 `Simplify()`；对整层铺地算"最窄连接"一次要几分钟，所以只对电源块和局部铜皮算。

### 没验证的

- 占位板没有信号走线和背面去耦电容；真板上 L1 的局部铜皮周围会更挤，L3 上的过孔更多。
- 方案 B 只跑了铺铜这一步，没有跑它的布线步骤。
- 没算压降、电流密度和温升。
- `compare.html` 用 Edge 无头模式截图确认过能显示；方向键切换没有人工试过。
