# 铜皮区域草图：H7 测试板原型（issue 16，一次性）
#
# 单位 mm。原点在板子左上角，x 向右、y 向下（等于板文件坐标减 100）。
# 顶点按顺序写，自动闭合；每条边只能是 0°、45°、90°。可以画出板外，KiCad 填充时按板边间距裁掉。
#
#   plane <层> gap=<块与块之间的缝> minw=<最小铜宽>     之后的 background / block 都在这一层
#   background <网络> <名字>                             这一层上各 block 外扩 gap 之后剩下的全部
#   block <网络> <名字> [chamfer=<倒角>]                 一块电源面，下面跟顶点
#   ground <层> <名字> minw=<最小铜宽> clr=<间距>        整层铺地
#   pour <层> <网络> <名字> [chamfer=] [minw=] [clr=]    外层局部铜皮，下面跟顶点
#
# chamfer：把每个直角切成 45°，切掉的长度不超过相邻边的 0.3 倍。

# ---------------------------------------------------------------- L3 电源层：三块
plane In2.Cu gap=0.5 minw=0.15

# +3V3A：只盖 codec（U6）和模拟 LDO 的输出

# ---------------------------------------------------------------- 地
