字节组在 L1 和 L6 之间换层的过孔阵怎么排

一个字节组是 8 根 DQ、1 根 DM 和一对 DQS。表层按已定的宽地线包地，线带宽 7.51 mm。SoC 和颗粒的球区相距 7.5 mm，除去两头的规则区，中间的直线段约 3.5 mm，蛇形也要放在这一段。图按比例画，单位 mm；线在各自的位置上画成直线，两头从球区展开的一段没有画。

先看一个事实：没有哪个字节组能整组在球区外换层

RK3568 的最外两圈球可以在 L1 直接出线，第 3 圈起必须在球区里打孔下去。四个字节组的球都是两种混在一起的（按封装文件和官方引脚表数出）：

所以球区外的过孔阵最多只有外圈那几根。走 L6 的字节组里，内圈的线出球区时已经在 L6 上，要从过孔阵中间穿过去。走 L1 的字节组里，内圈那 2 到 6 根先下到 L6，再回到 L1，或者一直走 L6 到颗粒。官方 EVB1 的做法相同，见页面末尾。

三种排法怎么比

排法样子好处代价
A 两排交错每个过孔打在线自己的位置上，线不拐弯；相邻的过孔前后错开 0.70 mm占长 1.10 mm，三种情形都一样；阵后还剩 2.25 mm 直线放蛇形；地铜条只在 DQS 对的两侧断开过孔旁的地铜条收窄到 0.275 mm（原宽 0.40）；同一格里另一根线离过孔盘 0.175 mm
B 挪到地铜条上线斜着横移 0.425 mm，过孔坐在地铜条的位置；排距 0.80 mm占长 1.20 mm；过孔离同格另一根线更远，避让圈不贴着它每个过孔切断一条地铜条（情形 2 是 9 处，共 6.15 mm）；每根线多两个 45° 拐弯；过孔盘到两侧邻线正好 0.15 mm，没有余量

要你定的事（每条后面是我的建议）
  1. 哪两个字节组走 L6。建议字节组 1 和 2：球区外各 5 个信号过孔，换成 0 和 3 是各 9 个；走 L1 的字节组 0 和 3 各只有 2 根线带过孔，反过来是各 6 根。
  2. 排法。建议 A。你说过多数时候交错更好；它最短，三种情形都过检查。
  3. 位置和排距。建议第一排紧贴 SoC 规则区外（过孔盘边离规则区边 0.15 mm），排距 0.70 mm，阵后的直线全部留给蛇形。
  4. 过孔旁地铜条收窄到 0.275 mm。建议接受，并把这一段铺铜的最小宽度设成 0.25 mm，否则铜条在每个过孔旁断开约 0.6 mm。
  5. 走 L1 的字节组里内圈那 2 根。建议照 EVB1：出球区后用同样的排法回到 L1，和同组的线一起走。这 2 根有两个过孔，同组其余的线没有，和“同组过孔数相同”不一致，要记成例外。另一个做法是一直走 L6 到颗粒球下的过孔。
  6. 外圈的球要不要也在球区里下孔，球区外不设过孔阵。建议不这样做，照 EVB1 让外圈在 L1 出线后再换层；球区里的过孔位留给电源、地和内圈的球。

没有核对的

  • 线是画在位置上的直线，不是真实扇出；外圈和内圈的线在线带里怎么排位（图里是每格一根外圈一根内圈）要等扇出工具给出线头顺序。
  • 避让圈直径 0.6 mm 是按“中心距 0.8 留 0.2 铜”倒推的，板厂实际做出来的大小没有查。
  • 没有过 KiCad DRC；间距由脚本按名义尺寸算。
  • EVB1 的数由子任务从板文件读出，我只复算了 DQS 对的过孔中心距一处。
  • 过孔阵在 SoC 北边（字节组 2、3）和西边画法相同，没有另画。
