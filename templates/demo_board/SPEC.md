# 演示板（STM32H743 + SDRAM 一个字节通道，六层）：方案定稿

状态：**模板，待用户批准**（2026-11-24 起草）。

这份文件有两个用途：

- 演示板的方案定稿：后面一批按它从头建这块板（`templates/demo_board/`），把构建驱动的每一步在一块小板上走一遍。
- 新板 SPEC 的样板：节的划分、每节的类别（已定 / 起点）、第 7.2 节的“本板取值”表、变更记录，新板照这个结构写。第 7.2 节的表是必填的，`python -m Tools.KiCadDesignTools.project.spec_check <板目录>` 检查它（构建的 layout 一步先跑它，不全或和数据文件不一致就停）。

这份文件是画板的唯一依据（PROC-8 的产出）。同目录的数据文件（由建板的那一批写）：

- `board.toml`：层的用途、模板、网络类、各步骤的参数。脚本读它，不读本文的表。
- `pins.csv`：MCU 用到的 22 个球（球号、圈号、信号、AF、总线组），从 `stm32h743_sdram/pins.csv` 摘出。
- `swap.csv`：SDRAM 一侧的数据位换位（第 9 节）。
- `unverified.md`：未核对项，一直带到交付。
- 其余数据（`place.toml`、`silk.toml`、`copper.sketch`、`length_groups.json`、规则文件 `demo_board.kicad_dru`、`rules_cases.py`、`routes_*.py`、`sch/main.py`）见第 11 节。工程文件、板子、原理图都由构建驱动生成，不进仓库。

每节标题后标了类别，改法不同（见第 15 节）：

- **已定**：改之前先问用户，批准后记入第 16 节。
- **起点**：可以直接改，在停点的评论里报告，并同步改本文。

每个会话先读：`CLAUDE.md`、`docs/shape/` 里和当前阶段有关的文件、`docs/rule-profiles/C-bga-065.md`、`docs/tools.md`、`templates/C-bga-065/README.md`、本文。交流用中文，KiCad 的概念用 Altium Designer 的对应说法解释。

## 1. 这块板验证什么（已定）

只做设计验证，不打样，电路不求能工作（SDRAM 只接一个字节通道和几根地址线）。它验证的是工具和流程：从模板起工程、规则、原理图、BGA 整块、布局、铜皮、走线、收尾，每一步都由构建驱动跑通，交付时逐条报“达到 / 没达到，差多少”：

| 验证什么 | 判据 |
|---|---|
| 从模板起工程（RUL-1） | `board.toml` 的 `template = "C-bga-065"`；工程文件、规则文件、六层空板都从 `templates/C-bga-065/` 来；规则金丝雀 OK，规则基准板 0 项不符 |
| 0.65 mm BGA 的扇出和背面去耦 | U1 用到的 22 个信号球和全部电源地球都引出；只用第 7.1 节的例外；背面 0402 去耦到电源球不超过第 7.2 节的上限 |
| 一个字节通道的等长和地址窗口 | FMC_D0–D7 + FMC_NBL0 组内差、地址对时钟的窗口、过孔数都满足第 7.2 节；DRC 的长度和等长规则 0 条报错；线形过 `track_shape` |
| 铜皮 | L2 整层地；L5 一块 `+3V3`，其余铺地，块间缝等于第 7.2 节的值；L1 一块局部铜皮；铜皮类未连接 0 |
| 收尾 | 丝印标注、板名、三个光学定位点；带原理图一致性的 DRC 只剩逐类说明过的丝印项 |

器件选择的原则：和 H743 板同型号，库、符号、封装都现成，不另选型。

来源：Tools/ 整理第 5 阶段（分支 `tools-consolidation`）的计划。

## 3. 接口清单和引脚分配（已定）

逐脚的表在 `pins.csv`，球号沿用 `stm32h743_sdram/pins.csv`（FMC 的复用固定，没有选择）。

| 部分 | 脚数 | `pins.csv` 的 group | 说明 |
|---|---|---|---|
| SDRAM 数据 | 9 | `SDRAM_DATA` | FMC_D0–D7（M14、L14、B12、C12、R8、P8、P9、R9）、FMC_NBL0（A4）：四边都有，扇出要从几个方向出 |
| SDRAM 地址 | 5 | `SDRAM_ADDR` | FMC_A0–A3（E2、H3、H2、J2）、FMC_BA0（K14） |
| SDRAM 时钟 | 1 | `SDRAM_CLK` | FMC_SDCLK（H14），经 R1 后叫 FMC_SDCLK_R |

## 4. 电源树（已定）

```
J1 +3V3（外部供电）→ C9 4.7 µF → +3V3（L5 的块）→ U1 的 VDD、U2 的 VDD / VDDQ
```

只有一条轨，没有稳压器。`+3V3` 的测试点就是 J1 的脚。

## 5. 网络分类和铜皮规划（已定）

| 网络 | 含义 | 类别和画法 |
|---|---|---|
| `GND` | 地 | 铜皮类：L2 整层；L5 除 `+3V3` 块以外铺地；L1、L6 空处铺地（BGA 规则区内不铺） |
| `+3V3` | 唯一的电源轨 | 铜皮类：L5 一块，盖住 U1、U2 和它们的背面去耦；J1 到 L5 的过孔之间是 L1 上的一块局部铜皮 |
| `VCAP1`、`VCAP2` | 内核稳压器的外接电容 | 走线类：短而宽（PWR 网络类）；球到过孔的狗骨线，电容焊盘压在过孔上，没有平面 |
| `HSE_IN`、`HSE_OUT` | 晶振 | 走线类，手写坐标（第 9 节） |
| 其余 | | 走线类 |

铜皮怎么画：外形写成文本草图 `copper.sketch`，边只用 0°、45°、90°（PWR-3），脚本检查通过才生成铺铜区（PWR-7）；不跑自动分割（PWR-4）；块间缝、最小铜宽写成草图里的参数，数值在第 7.2 节。地不走线，焊盘旁打过孔。

## 8. 板子尺寸和布局约定

### 8.1 已定

- U2 挨着 U1 的东边；对外的排针在板边。
- U1 不转（A1 在左上）。
- 层用途和背面规则（第 6 节）。

### 8.2 起点

- 板框 40 × 30 mm，横放，R1 圆角；不放安装孔。
- 粗分区（`place.toml`）：

```
           上边：U1 北边的总线带（L3 / L1），FID1、FID2
         ┌──────────────────────────────────────┐
  左边   │ Y1 晶振   [U1 MCU]   R1   [U2 SDRAM]  │ 右边
  J1 +3V3│ TP1                                  │
         └──────────────────────────────────────┘
           下边：FID3（左下）、J2 调试串口（U1 下面）、板名和日期（U2 下面）
```

- U1 中心 (14, 14)；U2 中心 (29, 16)，转 180°（字节通道 0 的球 K–R、7–9 列朝向 MCU 的东北），比 U1 低 2 mm，封装间距 6 mm。
- 晶振和两颗负载电容紧挨 U1 西边的 G1 / H1；R1 靠 U1 东边，转 90°。
- J2 放在下边 U1 的东南角下面（USART1 的 R14 / R15 在 MCU 东南角），不在左上。

## 9. 线序和等长（已定）

| 总线 | 分组和基准 | 容差 | 最大长度 | 蛇形 |
|---|---|---|---|---|
| SDRAM 数据（FMC_D0–D7 + FMC_NBL0，9 根） | 一个字节通道，组内互相比 | 见第 7.2 节 | 每根 30 mm | 画，这一组 |
| SDRAM 地址（FMC_A0–A3、FMC_BA0，5 根） | 每根对时钟（串阻两侧相加） | 见第 7.2 节 | 每根 30 mm | 不画 |
| 调试串口、晶振 | 不做等长 | 无 | 晶振球到晶振焊盘每根 7 mm | 不画 |

- 长度口径：焊盘到焊盘的走线长度，加过孔实际穿过的层间高度。
- 等长怎么报：字节通道用规则文件的 `skew` 规则，地址窗口由 `length_groups.json` 生成 `length` 规则；每次构建另出长度表。
- 换位：只在 SDRAM 一侧、字节内（第 3 节）。
- 出线层：数据线从 MCU 四边出来，要在两封装之间汇成一排，所以每根在球旁打狗骨孔下 L3（0、1 圈也一样），到 SDRAM 球旁再上 L1，每根 2 个过孔；NBL0、BA0、时钟的 MCU 一侧不换层，走 L1；地址线在 MCU 西边打狗骨孔下 L4，沿 MCU 的球行向东；时钟过 R1 后在 R1 旁下 L4。
- 蛇形（RTE-7）：脚本画线段加圆弧；数值在第 7.2 节；放在出了规则区之后的直线段上；先定补线区，再绕着它排线带。
- 晶振：Y1 两根线和两颗负载电容逐根手写坐标（`routes_local.py`），0.254 mm（XTAL 网络类），只走 L1，下面 L2 完整；球到晶振焊盘不超过 7 mm（HSE_OUT 5.9 mm，连同到 C2 的一段整网 7.45 mm）。
- 线序草图的验收（RTE-13）：同层无交叉；每个等长组按规划路径算的组内差在目标以内，补线区容量大于要补的量。

## 10. 连接器约定（接法已定，位置是起点）

**`+3V3` 排针 J1**：2 脚 2.54 mm，1 脚 `+3V3`（方焊盘）、2 脚 `GND`；左边。丝印标 `+3V3`、`GND`。

**调试串口 J2**：4 脚 2.54 mm，从左到右 GND、TX、RX、3V3；上边。3V3 只作转接器的电平参考；丝印按板子一侧标 `TX`、`RX`，1 脚方焊盘加丝印三角。

**丝印**：排针旁印信号名；板名和日期印在下边；位号放装配层。光学定位点三个，在顶面三个角，禁布圈边离板边至少 3.35 mm（嘉立创）。
