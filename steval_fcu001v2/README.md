# steval_fcu001v2

四层板 layout 测试：ST 官方评估板 STEVAL-FCU001V2（小四轴飞控）的原理图重新录入，加一块自己画的 40 × 40 mm 四层板。

- 原理图来源：`ref/steval-fcu001v2-schematic.pdf`（ST schematic pack Rev 2，2024-06），同目录有 BOM、data brief、UM2958。位号沿用 ST 的。
- 板子：嘉立创四层 JLC04161H-3313，1.6 mm，40 × 40 mm，四角 M3 孔。器件全在顶层，只有第二组电机焊盘在底层。
- 各层用途（2026-11-12 和用户定）：L1 信号和器件，L2 整层地，L3 电源层（`+BATT`，中间一块 `VDD`），L4 信号加铺地。

## 怎么重建

| 步骤 | 命令 |
|---|---|
| 原理图 | `sh scripts/sch_build.sh steval_fcu001v2 <输出目录>` |
| 网表进板 | `D:\KiCad\bin\python.exe scripts\net2pcb.py <输出目录>\steval_fcu001v2.net steval_fcu001v2\steval_fcu001v2.kicad_pcb` |
| 整板（布局、走线、丝印、泪滴、DRC） | `sh steval_fcu001v2/build_pcb.sh <报告目录>` |

`route.py` 里是手工走线（按区域分函数）和铺铜；自动布线的 21 个网络存在 `auto_tracks.json` 里，由 `route.py` 回放。`auto_tracks.json` 已经用 `scripts/auto_tidy.py` 拉直过（过孔和分叉点不动，自动走线从最初的 387 段减到 217 段）；布线器绕远的路径没有改。重跑自动布线的做法见 `CLAUDE.md` 的"走线"一节。

### 丝印（`silk.py`）

- **位号不上丝印**。按规则的最小字高 0.8 mm，102 个位号只有 55 个能找到不压焊盘的位置，所以一个都不印；位号仍在 F.Fab / B.Fab（AD 的 Assembly 层）上，装配图和贴片坐标不受影响。
- **只印功能标注**，字高 0.8 mm、字宽 0.6 mm、线宽 0.15 mm（`docs/design-rules.md` 的下限，没有再小）。共 52 条：正面 24 条、底面 20 条、电机焊盘正反各 4 条。
- **排针**：P3（I2C）、P6（TIM2）、P7（UART）是直插件，正反两面都标。底面每个引脚都有名字。正面 P7 和 P3 每个引脚都有名字（P3 的竖排在两排针之间）；P6 正面只标了两端的 `+` 和 `G`，中间四个引脚（TIM2 CH1–CH4，从 `+` 往 `G` 依次排）没有位置：排针塑料体到板边只剩 0.6 mm，和 P3 之间的空隙给了 P3 的引脚名。
- 为了放下引脚名，P3、P6、P7 封装自带的丝印外框删掉了，1 脚看方焊盘。
- 其余：`BAT` 和 `+`/`-`、`Mn+`（电机正极焊盘，另一个是负极）、`SWD`、`DIO`/`CLK`（TP1/TP2）、`RST`（按键和 TP3）、`CHG`（充电指示灯）、板名。LD1/LD2 两个用户灯没有标。
- **署名**（应用户要求）：底面蓝牙模块旁有一个四旋翼俯视图的小标志（4.5 mm 见方，自己画的）和三行字 `designed by` / `Claude` / `Fable 5.2 2026`，只在丝印层，压在走线和盖油过孔上，不压焊盘。

### 走线过程中改过的规则

都写在 `steval_fcu001v2.kicad_dru` 开头和 `docs/design-rules.md`。

- **过孔下限 0.6/0.3 → 0.45/0.2 mm**：0.5 mm 间距的 QFN 引脚之间放不下 0.6 mm 过孔（相邻走线中心距 0.5 mm，0.6 过孔至少要 0.502 mm）。0.45/0.2 是嘉立创多层板的能力下限，下单时确认是否加价。
- **孔径下限 0.254 → 0.2、上限 3.048 → 3.3 mm**：前者配合小过孔，后者是 3.2 mm 安装孔。
- **`usb2_skew` 加 `within_diff_pairs`**：原写法把 MCU 侧的差分对（16 mm）和连接器侧的（2 mm）互相比较。
- **`usb2_gap` 上限 0.7 → 0.8 mm**：U3 处绕地焊盘分开的那一段是 0.77 mm。
- **网络类通配符**：`?` 和 `[+-]` 在 KiCad 的网络类匹配里不生效，改成逐个网络名。
- **U7、U8、Q1–Q4 允许阻焊桥**：0.5 mm 间距 LGA 焊盘和 MOS 管 0.65 mm 间距的源/栅焊盘之间，阻焊桥只有 0.05 mm，低于 0.08 mm 下限，板厂会整组开窗。不打开这个选项会报 28 条 `solder_mask_bridge`。

### 走线过程中改过的布局

- LED 挪了两次：先从 MCU 左侧挪走（挡住 USB 差分在 L1 上唯一的通道），再从 MCU 正下方下移（给引脚扇出过孔让位）。
- 晶振下移 1.35 mm，让 `OSC_OUT` 直线进晶振，不挡 NRST 等引脚出线。
- C5、C7、C11、R22、C10、C14、C15、R30 各挪了 0.3–1 mm，都是为过孔或走线通道让位；C10 转了 180°。
- 充电的阻容一列（R30、C15、C14）上移 1.05 mm，USB 差分才能在它下方横移到 U3。

## 和 ST 图纸不一样的地方

| ST 图纸 | 这里 | 原因 |
|---|---|---|
| `V_USB`、`VBAT+` | `VBUS`、`+BATT` | 用 KiCad 自带电源符号 |
| `USB_DP` / `USB_DM`（MCU 侧） | `USB_D+` / `USB_D-` | KiCad 靠 `+`/`-` 后缀识别差分对 |
| `DP` / `DM`（连接器侧） | `USB_CONN_D+` / `USB_CONN_D-` | 同上 |
| `MOTORn-` | `MOTORn_N` | 避免被当成差分对的负端 |
| R25（0R，接在两种地符号之间） | 去掉，只有一个 `GND` | 四层板有完整地平面 |
| 电机排针 P1 / P4 / P2 / P5（2 针） | 裸焊盘 MP1–MP16（每个电机 `+BATT` 和 `Mn_OUT` 各一个，1.5 × 3 mm；MP1–8 在顶层，MP9–16 在底层同一位置） | 用户要求 |
| CN1 Molex 47590-0001（micro-AB，沉板，板边要开槽） | Molex 47346-0001（micro-B，贴片，直板边） | 不开槽；引脚顺序相反，USB 差分对从 MCU 到座子不用交叉 |
| 没有安装孔 | H1–H4，M3 | 原型板固定用 |
| 栅极、LED 阳极等没有名字的节点 | `Mn_GATE`、`LDn_A`、`Mn_OUT`、`CHG_PROG`、`CHG_STAT`、`USB_SHIELD`、`USBLC_VBUS` | 标号画法需要名字 |

## 未核对项

没有对着规格书核对过的引脚、封装和参数。

1. **Q1–Q4 型号和封装**：ST 图纸写 STL10N3LLH5（8 脚，1–3 源极、4 栅极、5–8 漏极），BOM 写 STL6N3LLH6（PowerFLAT 2×2）。这里按图纸的引脚功能，封装用了 3.3×3.3 的通用 VSON-8，没核对过 ST 的推荐焊盘。
2. **U3 封装**：用了尺寸相同的 TI USON-6 顶替，焊盘编号顺序和尺寸没对过 USBULC6-2M6 规格书。
3. **U1 封装和天线净空**：假定 BLUENRG-M0A 和 SPBTLE-RF 焊盘相同。`ST_SPBTLE` 封装自带 12 × 12 mm 的四层禁布区，布局和走线都避开了；这个尺寸是 SPBTLE-RF 的。蓝牙 SPI 五根线从模块下方（禁布区外）的 L1 走，模块底面是否允许走线没查。
4. **U4 引脚**：按图纸上的引脚号（1 CHRG、2 GND、3 BAT、4 VCC、5 PROG）录入，没对过 STC4054 规格书。
5. **U8 引脚**：LSM6DSR 借用 LSM6DSL 符号，图纸上的引脚号和符号一致，没对过规格书。
6. **S1**：KMR231GLFS 用了带接地脚的 `KMR2xxG` 封装，接地脚接 GND；型号是否带接地脚没查。
7. **D5 极性**：按图纸 1 脚接 VBUS；封装的 1 号焊盘是否是阴极没查。
8. **Y1**：BOM 里晶振的型号没读出来（PDF 表格文字错位），封装暂用 3225 四脚，负载电容 15 pF 沿用图纸。
9. **排针**：BT1 用 2.54 mm 弯针，P3、P7、P6 用直针，P8 用 1.27 mm 2×5 贴片针；BOM 的具体料号没逐个对封装。
10. **阻容封装**：统一 0402（图纸上 R1 标 0805、R26 标 0201，BOM 都是 0402）；R12、R13、R16、R17 按 BOM 用 0603。
11. **原板尺寸和外形**：没查。V1 的 Gerber 是双层板，没有官方四层 layout 可对照。
12. **叠层数据**：3313 半固化片 0.0994 mm / Er 4.1、芯板 1.265 mm 是凭记忆写的，没在嘉立创阻抗计算器上核对。USB 线宽 0.15 / 间距 0.15 mm 是按 IPC-2141 公式估的（约 88 Ω）；这块板的 USB 只有全速。
13. **CN1 板边位置**：板边放在封装原点下方 2.7 mm（外壳焊盘外 0.55 mm），没对过 Molex 47346-0001 图纸上的板边尺寸。
14. **0.45/0.2 mm 过孔的价格档**：是否在嘉立创四层板的免加价范围内没查。
15. **L3 上 `+BATT` 的通流**：L3 的 `+BATT` 是围着 `VDD` 岛的一圈，上边在蓝牙天线禁布区下方只有约 2.6 mm 宽（0.5 oz 铜）。四个电机同时峰值电流时的压降和温升没算。

## ERC

0 错误，1 条警告：U8 的 SDx（双向）接在 VDD 上，和 LDO 输出（电源输出）同网。ST 图纸就是把 SDx/SCx 接 VDD 的，保留。
