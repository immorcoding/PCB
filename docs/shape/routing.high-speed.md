# 走线 · high-speed

高速接口的线：差分对、线距和包地、参考面和换层回流。 索引：[routing.md](routing.md)。

数值不写在这里：接口的起点值在接口档（DDR3 是 [if-ddr3.md](../rule-profiles/if-ddr3.md)），每块板的值在它的 `SPEC.md`。

## Rules

- **RTE-16** · exploring · 差分对：P、N 走同一层，过孔数相同，过孔并排对称；对内偏差的目标和上限写在 SPEC；对内补偿放在失配产生的那一端（从芯片一侧规则区内的展开段排起，排不下的顺着伸到规则区外的直线段），不放在对端；补偿用圆角矩形的小耳朵，画在短的那根上、向外凸，高度上限和腿间距写在接口档；整对一起绕沿用 RTE-7 的圆弧蛇形；KiCad 的间隙规则不写上限，并行段间隙恒定由工具查。 _Why:_ 瑞芯微要求 DQS、CLK 对内 < 12 mil，而 RK3568 字节 2 的 DQS 对在封装里就差 13.4 mil，必须在板上补；TI 要求补偿靠近失配端；ST 的“对内不许补”在这里做不到。 _Source:_ [高速规则票](https://github.com/immorcoding/PCB/issues/43)、[差分对原型票](https://github.com/immorcoding/PCB/issues/37)、[差分对工具票](https://github.com/immorcoding/PCB/issues/36)
- **RTE-17** · exploring · 线距和包地照芯片厂的要求做：倍数按边到边算；BGA 规则区内豁免，每根线的收窄段长度列出；蛇形的腿间距用同一套倍数；间距用 KiCad 网络类之间的间距规则判，蛇形腿距由工具的参数保证。厂商要求表层包地的线（瑞芯微：DQS、CLK 全程包地，DQ / DM 走 G-S-S-G，地线按间隔打地过孔）默认照做，不拿“地不走线”或“线带要紧凑”否掉。 _Why:_ 各家的线距写法差一个线宽（中心距或边到边、按线宽或按介质厚度），不写明口径就没法判；我第一次的建议把包地推给原型去定做不做，用户纠正：以公开资料为准。 _Source:_ [高速规则票](https://github.com/immorcoding/PCB/issues/43)
- **RTE-18** · exploring · 有阻抗要求的线，最近的参考面是整层地，定叠层时写明每个信号层参考哪一层；不以分块的电源层为参考（电源层照 PWR-8 分块）。换层时信号过孔旁配地过孔，距离上限写在 SPEC，一个地过孔可以被几个信号过孔共用，球区内旁边有地球的过孔就算数，放不下的逐处列给用户。球区外，高速线的换层过孔排开到避让圈之间留铜，线不跨、不沿着参考层上的槽走，跨了算不通过；球区内不查。线离参考面边缘的距离写在 SPEC。 _Why:_ 瑞芯微：DDR 的参考层是完整地平面、避免连续过孔切断回流、不跨分割、离参考面边缘 > 40 mil、换层过孔 25 mil 内有地过孔；RTE-5 的“槽不设上限”是 H743 板（SDRAM）上定的，规格档 C 写明更高速的接口另定。 _Source:_ [高速规则票](https://github.com/immorcoding/PCB/issues/43)

## Signals

- 2026-11-27 · cite · RTE-16 · [差分对原型票](https://github.com/immorcoding/PCB/issues/37)和[差分对工具票](https://github.com/immorcoding/PCB/issues/36)把规则里留给工具定的两处定了：补偿是圆角矩形小耳朵（上限 0.20 mm、腿间 3W），间隙规则不写上限；补偿的位置从“出规则区后的第一段直线”改成“从规则区内的展开段排起”（官方板两种位置都有）。规则正文已照改。都只有原型图，没有过 DRC、没有在板上走过。
- 2026-11-27 · correction · RTE-16 · 主会话把整对蛇形改成标准圆弧时，顺手把已定的小耳朵也改成了没有平顶的纯圆弧，没有问用户；小耳朵腿之间也没留 3W（只有约 0.22 mm）。用户看图指出，两处都改回。
- 2026-11-27 · cite · RTE-17 · [包地原型票](https://github.com/immorcoding/PCB/issues/47)定了画法：默认宽地线（对内 0.30、隔地 0.70、地铜 0.40 放 0.4 / 0.2 过孔，过孔间隔 ≤ 2.54 mm），地铜优先由铺铜形成，到不了的地方画同宽的地线；一个字节组的线带宽 7.51 mm（不包地 4.56）。数值在接口档。蛇形处的间隙没有定。
- 2026-11-27 · correction · RTE-17 · 同一张票上我两次把用户的话写过头：先写成“地不手画”（用户：只是尽量用覆铜，和电源区用铜皮一个意思），再写成“窄地线可以自选”（用户：优先宽地线，写进 SPEC，要换窄地线先修订 SPEC）。
