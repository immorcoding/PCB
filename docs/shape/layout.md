# 布局

器件怎么摆，以及布局按什么验收。间距、过孔等数值在 [design-rules.md](../design-rules.md)。

Next id: LAY-10

## Pillars

- 器件围着铜皮摆，不是摆完器件再找地方放铜皮。
- 布局合不合格，看的是后面能不能走线、能不能供电。

## Open questions

- 去耦电容到电源脚的距离上限取多少（按容值和封装分档）？等下一块板的方案阶段定。

## acceptance

布局交审查前要满足的条件。

### Rules

- **LAY-2** · provisional · 布局按三项指标验收：每颗去耦电容到它的电源脚的距离、每个引脚或球有没有出线通道、每路电源的焊盘和过孔能不能连成一块。 _Why:_ 六层废弃板的去耦离芯片 10–27 mm，PMIC 的几个引脚没有引出位置，各路电源的过孔散布全板。
- **LAY-3** · provisional · 交审查前试走四类网络：关键信号、电源主干、去耦、局部电路（晶振、降压环路），试走暴露的问题在布局阶段改掉。 _Why:_ 四层板没试走就交了布局，走线中途改了十几个器件的位置；六层废弃板只试走了 DDR。
- **LAY-9** · exploring · 布局验收时跑 kicad-happy 的 `emc` skill 查去耦和地平面，发现逐条甄别；结果和 LAY-2 的三项指标一起给用户。 _Why:_ 六层废弃板的去耦离芯片 10–27 mm，布局阶段跑一次去耦检查就能发现。
- **LAY-6** · provisional · 封装自带的禁布区和板边开槽在布局阶段查。 _Why:_ 四层板的蓝牙模块带一个比外框大的禁布区，外框不重叠也报错。

## placement

摆放的顺序、间隔和算法。

### Rules

- **LAY-1** · provisional · 摆器件前先画每路电源的铜皮区域草图，器件围着铜皮区域摆。 _Why:_ 用户 2026-11-15 的复盘：人工摆器件时已经想好每块铜皮的形状；六层废弃板是摆完才考虑铜皮。
- **LAY-4** · exploring · 阵列里器件的间隔，按当板规则算够过一根线；大电容之间够放一个过孔。 _Why:_ 0.1 mm 的间隔下，0402 之间只有正中间能过线，大电容旁边放不下过孔。
- **LAY-5** · exploring · 背面器件不放在顶面器件焊盘的投影下，约定的 BGA 背面去耦除外。 _Why:_ 背面电容的过孔会顶到上面的焊盘；六层废弃板的 PMIC 输入电容正好压在散热焊盘下。
- **LAY-7** · provisional · 焊盘坐标从板文件里打出来再算，不按封装方向心算。 _Why:_ 四层板上 MCU 引脚行号心算错了一格。
- **LAY-8** · provisional · 排针、测试点旁边在布局阶段就给丝印留位置（排针之间、排针到板边至少一列字的宽度）；位号留不留也在这一阶段问用户。 _Why:_ 丝印放不下时只能回头挪器件。
