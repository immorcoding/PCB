# 布局

器件怎么摆，以及布局按什么验收。间距、过孔等数值在 [design-rules.md](../design-rules.md)。

Next id: LAY-12

## Pillars

- 器件围着铜皮摆，不是摆完器件再找地方放铜皮。
- 布局合不合格，看的是后面能不能走线、能不能供电。
- 规则跟着事实走：厂商指南、板厂能力和实测推翻了哪条，就改哪条（PROC-16）。

## acceptance

布局交审查前要满足的条件。

### Rules

- **LAY-2** · provisional · 布局按三项指标验收：每颗去耦电容到它的电源脚的距离、每个引脚或球有没有出线通道、每路电源的焊盘和过孔能不能连成一块。小去耦到它的电源脚或球的距离上限在规格档里，大电容不设上限。 _Why:_ 六层废弃板的去耦离芯片 10–27 mm，PMIC 的几个引脚没有引出位置，各路电源的过孔散布全板；ST 自己的 H7 板上去耦到最近电源球是 0.35–2.04 mm。
- **LAY-3** · provisional · 交审查前试走四类网络：关键信号、电源主干、去耦、局部电路（晶振、降压环路），试走暴露的问题在布局阶段改掉。 _Why:_ 四层板没试走就交了布局，走线中途改了十几个器件的位置；六层废弃板只试走了 DDR。
- **LAY-9** · exploring · 布局验收时跑 kicad-happy 的 `emc` skill 查去耦和地平面，发现逐条甄别；结果和 LAY-2 的三项指标一起给用户。 _Why:_ 六层废弃板的去耦离芯片 10–27 mm，布局阶段跑一次去耦检查就能发现。
- **LAY-6** · provisional · 封装自带的禁布区和板边开槽在布局阶段查。 _Why:_ 四层板的蓝牙模块带一个比外框大的禁布区，外框不重叠也报错。

## placement

摆放的顺序、间隔和算法。

### Rules

- **LAY-1** · provisional · 摆器件前先画每路电源的铜皮区域草图，器件围着铜皮区域摆。方案阶段的分区只是起点：定下来的是分区背后的理由，碰到理由先问用户，块的位置和连接器所在的边直接改、当场报告。过孔的位置也跟着铜皮区域草图走。 _Why:_ 用户 2026-11-15 的复盘：人工摆器件时已经想好每块铜皮的形状；六层废弃板是摆完才考虑铜皮；H7 的铜皮原型上一个地过孔占在 `+5V` 支路中间，最窄只剩 1.57 mm。 _Source:_ [决定票](https://github.com/immorcoding/PCB/issues/13)
- **LAY-4** · exploring · 阵列里器件的间隔，按当板规则算够过一根线；大电容旁边够放一个过孔（一对里有一颗是大电容就算，门槛在规格档里）；`placement.place_check` 报不够的对数。 _Why:_ 0.1 mm 的间隔下，0402 之间只有正中间能过线，大电容旁边放不下过孔。
- **LAY-5** · exploring · 背面器件不放在顶面器件焊盘的投影下，约定的 BGA 背面去耦除外；BGA 背面的去耦用规格档定的小封装，贴着所服务球的过孔摆。 _Why:_ 背面电容的过孔会顶到上面的焊盘；六层废弃板的 PMIC 输入电容正好压在散热焊盘下；用户 2026-11-23：BGA 下方都该用小封装（H743 板是 0402）。
- **LAY-7** · provisional · 焊盘坐标从板文件里打出来再算，不按封装方向心算。 _Why:_ 四层板上 MCU 引脚行号心算错了一格。
- **LAY-8** · provisional · 排针、测试点旁边在布局阶段就给丝印留位置（排针之间、排针到板边至少一列字的宽度）；位号留不留也在这一阶段问用户。 _Why:_ 丝印放不下时只能回头挪器件。
- **LAY-11** · exploring · 接口的附属器件（端接、VREF 的分压和去耦、ZQ 电阻、复位电容）在线序草图阶段就占位，位置要求照芯片厂的指南写进 SPEC；厂商要求在分叉点上的器件和分叉点一起定位置。 _Why:_ 瑞芯微要求 CLK 的 RC 必须在 T 型的分叉点上，VREF 的电容贴着球；线序排完再找地方放，分叉点就得挪。 _Source:_ [高速规则票](https://github.com/immorcoding/PCB/issues/43)

## changes

布局定了之后怎么改。

### Rules

- **LAY-10** · provisional · 布局的大动从集成分支另开 `try/<改什么>` 分支：两边各跑同一张指标表（PROC-4），连同对比图给用户选，选中的合回，没选中的留档不合并。大动指碰到分区背后的理由、一次挪两个及以上的块或改板框尺寸、改层用途或背面规则；小改直接在集成分支上改并报告。板框可以改，但不能拿已定的方向换空间（比如把 IC 挪到背面再缩板框）。 _Why:_ 用户 2026-11-16 定；四层板布局后缩了两次尺寸，每次整板重摆，没有并排对比过。 _Source:_ [决定票](https://github.com/immorcoding/PCB/issues/13)

### Signals

- 2026-11-21 · LAY-10 · 相关：QSPI 换位置和 RJ45 下移各按一个块的小改处理，没有开 try 分支。
- 2026-11-21 · LAY-10 · 起作用也有摩擦：用户提出以太网口西移，我按“改板框”开了 `try/eth-west`；用户随后说明板框不变、只是接口本体探出板边，改动缩成一个块平移加几个邻居下移，按字面是小改。“连接器本体探出板边”算不算改板框，规则没写。
- 2026-11-21 · LAY-10 · 用户选了 `try/eth-west`（“暂定就这样，后续有问题再调”），已合回 `integration-h743`。
- 2026-11-28 · friction · LAY-10 · RK3568 验证板不送打样，板框只是设计边界。用户同意板框按余量定（西、北为 DDR 规则区外 2 mm，东、南为 SoC 规则区外 6.5 mm），摆位或分叉过孔带变了就按余量重算、不再单独问，不开 `try/` 分支。规则没有区分“要送厂的板框”和“只当设计边界的板框”；用户 2026-11-28 定暂不改规则，复查时再看。[决定票](https://github.com/immorcoding/PCB/issues/60)
