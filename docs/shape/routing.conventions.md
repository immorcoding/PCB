# 走线 · conventions

动手前的约定和给用户看的时机。 索引：[routing.md](routing.md)。

## Rules

- **RTE-5** · provisional · 动手前和用户定各层的用途和约定，能量化的给出数字，数字写进板子的 `SPEC.md`，不写在这里（例：底层允许走哪些网络、总长多少）。过孔数上限只给有时序要求的线，其余只报个数，每次构建列出；等长窗口紧的组和每个字节组，成员的过孔数相同、层序相同。换参考面的地方配地过孔。过孔避让在平面上连成的槽不设长度上限，BGA 下方更不设；高速接口的线在球区外另按 RTE-18。 _Why:_ 约定没有数字就没法说守没守住；各板的接口和球距不同，数字跟着板子走；H743 板上自己取的槽长上限卡住十几个球，用户：手画时不管这个，BGA 下方不能有这条。 _Source:_ [连接器票](https://github.com/immorcoding/PCB/issues/17)
- **RTE-6** · provisional · 走完第一个区域就把局部图给用户看走线风格，用户说了"最后一起看"也给。 _Why:_ 四层板全部走完才交，DRC 干净但被判不整齐，返工三轮。
