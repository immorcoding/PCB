# 走线 · shape

线形和完成标准。 索引：[routing.md](routing.md)。

## Rules

- **RTE-8** · provisional · 走线的完成标准有两条：`kicad-cli pcb drc --refill-zones --severity-all` 未连接为 0、剩余项逐条有解释；`Tools/KiCadDesignTools/analysis/track_shape.py` 按 design-rules.md"走线形状"达标，没达标的逐处列给用户。 _Why:_ 四层板上每段线都在 0°/45°/90°、DRC 干净，仍被判不整齐。
- **RTE-9** · provisional · 线形清单里剩下的每一处都要看图再下结论，不能按类别概括。 _Why:_ 四层板上把 13 处连续折弯一概说成"绕焊盘"，其中 2 处是小倒角直角，被用户看出来了。
- **RTE-10** · provisional · 1–2 mm 的短线（电容到引脚、引脚到过孔）把器件摆到和引脚对齐，走一段直线；不为了每个端点都 45° 进出而在 1 mm 里折三四次。 _Why:_ 四层板返工时用户指出的问题之一。
- **RTE-11** · provisional · 分叉只放在焊盘中心；线上的 T 型、Y 型分叉和过孔处的 90° 转弯要么改掉，要么逐条解释。例外：板子 SPEC 的拓扑表里声明过的分叉点（网络和坐标）可以落在过孔中心，主干进过孔、两条分支从同一个过孔出，不落在线的中段；厂商要求放在分叉点上的端接器件算分叉点的一部分。 _Why:_ `corner_angle` 对线上的三向分叉一律报错；瑞芯微给两颗 DDR3 的地址、控制和时钟定的是 T 型，CLK 的 RC 必须在分叉点上。 _Source:_ [高速规则票](https://github.com/immorcoding/PCB/issues/43)
