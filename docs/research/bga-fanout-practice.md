# 调研：UFBGA176+25 和 BGA SDRAM 的扇出做法

对应票：[#6](https://github.com/immorcoding/PCB/issues/6)（地图 #1）。调研日期 2026-11-15。分支 `research/bga-fanout-practice`，不合并。

本文回答六个问题：ST 推荐的焊盘和阻焊、狗骨头过孔还是盘中孔、几圈球要几层信号层、内圈电源/地球怎么办、背面去耦怎么放、SDRAM 一侧同样几件事；最后和规格档 C（`docs/rule-profiles/C-bga-065.md`）的球距计算表对照。

每条结论标了来源。标记含义：**[原文]** 读到了一手来源的原文、原图或原始文件；**[实测]** 我从一手来源的文件里量出来的（Gerber、KiCad 库），步骤见附录；**[推导]** 我用上面两类数据算出来的，没有人替我验证过；**[未核实]** 没有查到或只有二手说法。

## 一、结论（压缩版）

| 问题 | 建议 | 状态 |
|---|---|---|
| MCU 焊盘 | 铜焊盘 Ø0.30 mm 圆形，非阻焊定义（NSMD） | [原文] ST 数据手册表 217；KiCad 封装已是 0.3 |
| MCU 阻焊开窗 | Ø0.38 mm（单边扩 0.04）。ST 写 0.40 typ，但 0.40 会让球间过线到开窗边只剩 0.08，低于嘉立创"开窗到邻线 ≥ 0.09" | [原文]+[推导]，要用户拍板 |
| MCU 过孔 | 球间位置（四球中心）的狗骨头，0.30 / 0.15 mm（和规格档 C 一致）。嘉立创说 0.15 孔"要多收费，下单时选对应过孔选项" | [原文] 嘉立创；[推导] 几何 |
| 球焊盘上打孔 | 不需要。每个球都有狗骨头位。ST 自己的板只对 7 个外圈球用了激光盲孔盘中孔 | [实测] |
| 几圈几层 | 环 0、环 1（104 球）顶层直出；环 2、环 3（最多 46 个信号球）狗骨头通孔后从 L4 出，L6 作备用。下限 2 个信号层，保守 3 个 | [推导]，要试走验证（LAY-3） |
| 内圈电源/地 | 中心 25 个 VSS 球用球间位通孔（9–16 个）；空圈（环 4）的 24 个位置可以直接放过孔 | [实测]+[推导] |
| 背面去耦 | 全放背面，直接在球阵正下方。一个焊盘接就近的狗骨头通孔，另一个焊盘同样短线接旁边 VSS 球的狗骨头通孔 | [原文] ST 应用笔记；[实测] ST 板 |
| SDRAM 焊盘 | Micron 90 球 VFBGA：球距 0.8，焊盘 Ø0.33 ±0.025；开窗建议 Ø0.43 | [原文] 焊盘；开窗是 [推导] |
| SDRAM 出线 | 全部 90 球在顶层就能出，不需要内层；28 个电源地球用狗骨头过孔，中间空出的 3 列（2.87 mm 宽）是通道 | [推导] |
| 对规格档 C 的修改 | 焊盘 0.35 → 0.30；加"阻焊开窗到邻线"一行；加"0.45/0.20 通孔放不下"一行；加环 0–1 的出线容量一行；盘中孔约定里"内圈出不来的球"在这个封装上不会出现 | 见第九节 |

## 二、封装和球阵

### 2.1 封装

STM32H743IIK6：订购编码里 K 表示 UFBGA、球距 0.65 mm。[原文：[DS12110](https://www.st.com/resource/en/datasheet/stm32h743vi.pdf) Rev 11，第 9 节订购信息，p.346/357]

UFBGA176+25 本体 10 × 10 mm，球距 e = 0.65，球径 b = 0.24 / **0.29** / 0.34 mm（最小/典型/最大），D1 = E1 = 9.10 mm，高 A ≤ 0.60。[原文：同上，表 216，p.338–339/357]

### 2.2 球阵（15 × 15 网格，24 个位置空着，中心 25 球）

数据来源：KiCad 10 的符号 `STM32H743IIKx`（`MCU_ST_STM32H7.kicad_sym`）和封装 `UFBGA-201_10x10mm_Layout15x15_P0.65mm`，我把 201 个球的位置和名字对出来，并和 DS12110 图 10（p.60/357，上视图）对照：A–D、J–R 各行名字顺序完全一致，E–H 行只差几个多行标签（PC14-OSC32_IN、VDD33USB 等）在文字提取里被拆开，空位和中心块也一致。[原文+实测]

"环"从最外圈数起：环 0 是 A 行、R 行、1 列、15 列；环 1 是 B 行、P 行、2 列、14 列，依此类推。

| 环 | 球数 | 信号 | 电源 | 地 | 备注 |
|---|---|---|---|---|---|
| 0 | 56 | 51 | 3（VBAT、VDDA、VREF+） | 2（VSSA、VREF-） | |
| 1 | 48 | 46 | 0 | 2（F2、G2） | |
| 2 | 40 | 27 | 13（VDD ×11、VDD33USB、VCAP） | 0 | |
| 3 | 32 | 19 | 3（VDD ×2、VCAP） | 10 | |
| 4 | 0 | | | | 24 个位置全空，形成一圈"护城河" |
| 中心 5 × 5 | 25 | 0 | 0 | 25（全 VSS） | |
| 合计 | 201 | 143 | 19 | 39 | |

143 个"信号"= 140 个 GPIO + NRST、BOOT0、PDR_ON，和数据手册的 140 个 I/O 对得上。"用到六成以上引脚"就是至少 84 个。

信号球的分布：环 0–1 共 97 个，环 2–3 共 46 个。按边分，环 2 每边 6–8 个信号球，环 3 每边 4–6 个。[实测]

### 2.3 FMC 的 SDRAM 引脚散在四条边上

32 位 SDRAM 要用的 FMC 引脚在 STM32H743 上没有重映射余地（数据手册 AF 表），我把 53 个固定引脚落到球阵上：

| 环 | 固定的 FMC SDRAM 引脚数 |
|---|---|
| 0 | 10 |
| 1 | 20 |
| 2 | 17 |
| 3 | 6 |

也就是说 **32 位 SDRAM 总线本身就有 23 个信号落在环 2–3**，要走过孔换层。按边分（上视图，A 行在上、1 列在左）：下边（R 行一侧）16 个、右边（15 列一侧）17 个、左边（1 列一侧）9 个、上边（A 行一侧）6 个，另有 5 个在角上。SDNWE、SDNE0、SDCKE0 各有两个可选引脚（PC0/PH5、PH3/PC2_C、PH2/PC3_C），环数随选择变化。[引脚与 FMC 功能的对应：原文，DS12110 的引脚功能表（Port D/E/F/G/H/I 各行，AF12）；落到环和边上：实测]

这件事对"线序"（RTE-1）重要：SDRAM 放在板子哪一侧，就有一半以上的 FMC 信号要绕过 MCU 的另外几条边。

## 三、焊盘和阻焊

### 3.1 ST 的推荐

DS12110 表 217（UFBGA176+25 的 PCB 设计规则示例）：[原文，p.339/357，图 129]

| 项 | 值 |
|---|---|
| 球距 | 0.65 mm |
| Dpad（铜焊盘） | **0.300 mm** |
| Dsm（阻焊开窗） | **0.400 mm typ.**（取决于阻焊对位公差） |
| 钢网开口 | 0.300 mm |
| 钢网厚度 | 0.100–0.125 mm |
| 焊盘出线宽度 | 0.100 mm |

图 129 画的是开窗大于焊盘、线从焊盘侧面引出，就是非阻焊定义（NSMD）。但"推荐 NSMD"这句话数据手册只给 UFBGA169（0.5 mm 球距，表 213）写了，UFBGA176+25 没有明说。[原文]

AD 的对应说法：NSMD 就是阻焊扩展（Solder Mask Expansion）为正，开窗比焊盘大；焊盘定义里的 Dpad 是 Top Layer 的焊盘尺寸，Dsm 是 Top Solder 的开口。

KiCad 自带封装 `UFBGA-201_10x10mm_Layout15x15_P0.65mm`：焊盘 0.3、阻焊边距 0.05（开窗 0.4）、锡膏边距约 0（开口 0.3），三项都和表 217 一致。[实测]

注意两点：
- 数据手册早期版本改过同系列 TFBGA240+25 的 Dpad/Dsm（修订记录前三版那一栏："Updated dpad and dsm in Table 136: TFBGA240+25"），说明这张表出过错，用之前核对当前版本。[原文，p.349/357]
- 规格档 C 的计算表假设焊盘 0.35 mm，**这个封装的真实值是 0.30**。

### 3.2 ST 自己的板子用得更小

ST 官方板 STM32H735G-DK（主板 MB1520）发布了制造文件（Gerber），我读了 C 版：[实测，来源：[MB1520 制造文件](https://www.st.com/resource/en/board_manufacturing_specification/mb1520_manufacturing.zip)，v2.1，页面见 [STM32H735G-DK](https://www.st.com/en/evaluation-tools/stm32h735g-dk.html)]

- 板上 U6（C02 的贴片坐标文件里写作 STM32H725IGK6U，封装 `ICC_UFBGA201_176+25_10X10_P065`）：球焊盘 **Ø0.25**，阻焊开窗 **Ø0.35**（单边扩 0.05）。比数据手册的 0.30/0.40 小。
- 球阵下面的所有过孔都盖油（阻焊层在阵列内只有 201 个球开窗，没有过孔开窗）。
- 同一块板上还有第二个 UFBGA176+25（U13，STM32F723，ST-LINK 用），焊盘同样是 0.25。

许可：ST 开放平台许可协议（OPLA，[www.st.com/opla](https://www.st.com/opla)）。我只读了尺寸，文件没有入库，没有再分发。

### 3.3 嘉立创的阻焊规则

嘉立创工艺能力页（2026-11-15 读取，[PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities)）：[原文]

- 阻焊开窗扩展 1:1（2025 年 6 月 LDI 设备升级；"Pad size:soldermask opening can be 1:1"）。我的理解是嘉立创不替你加扩展，**开窗按你给的文件来**，所以 KiCad 里要自己把阻焊边距设好。这个理解没有核实（也可能只是说"允许开窗等于焊盘"）。
- "Keep at least 0.09 mm clearance between soldermask openings and neighboring traces."
- 阻焊桥最小 0.10 mm（绿、红、黄、蓝、紫），黑白 0.13 mm。
- BGA 焊盘最小 0.2 mm；0.2–0.25 mm 的焊盘要用 ENIG；BGA 焊盘到走线 ≥ 0.1，多层板局部可到 0.09。

### 3.4 建议

铜焊盘 Ø0.30，开窗 **Ø0.38**，锡膏开口 Ø0.30。理由 [推导]：线从两个焊盘正中间过时，线边到开窗边 = (0.65 − Dsm − 线宽) / 2。

| Dsm | 0.09 线 | 0.10 线 | 球间阻焊桥 |
|---|---|---|---|
| 0.35（ST 板） | 0.105 | 0.100 | 0.30 |
| 0.38 | **0.090** | 0.085 | 0.27 |
| 0.40（ST 数据手册） | 0.080 ✗ | 0.075 ✗ | 0.25 |

按 ST 的 0.40，线到开窗边只有 0.08，不满足嘉立创的 0.09。用 0.38 刚好够 0.09 的线；真要走 ST 说的 0.10 线宽，开窗要降到 0.37 以下。这个取值是新的规则例外（改 KiCad 封装的阻焊边距），按 RUL-5 先问用户。

## 四、过孔：狗骨头还是盘中孔

### 4.1 ST 官方板的做法

MB1520 C 版，我从钻孔报告和 Gerber 里量出来的：[实测]

- 6 层（GTL、G1–G4、GBL）。钻孔：通孔 0.2 mm（1099 个，焊盘 0.45）、**激光盲孔 0.1 mm** 顶层→L2（217 个）和 L5→底层（53 个）（盲孔焊盘 0.25，即孔 + 0.15）。
- U6 球阵内：通孔 44 个，盲孔 54 个。
  - 盲孔里 7 个在球焊盘上（盘中孔，都在环 0–1）；46 个在球间位置。
  - 环 2 的 40 个球里 33 个用盲孔狗骨头（球间位置，离球 0.46 mm），5 个直接从顶层出线，2 个用通孔。
  - 环 3 的 32 个球里 8 个用盲孔，24 个用通孔。
  - 中心 25 个 VSS 球：16 个通孔，一个球间位放一个（4 × 4 个球间位全放满）。
  - 环 0–1 共 104 个球里 86 个顶层直接出线。
- 线宽：L1 阵列内 0.1 和 0.127 mm 两种；L2 是 0.1；L4 是 0.1–0.104 和 0.127；L6 是 0.127。L3、L5 在阵列内没有任何走线，是平面。
- 所以 ST 在球阵下用了 4 个信号层（L1、L2、L4、L6），靠激光盲孔把环 2 搬到 L2，通孔主要给环 3 和电源地用。

这是 HDI（激光盲孔）板。规格档 C 的 JLC06161H-3313E 是标准叠层，没有盲孔。

数据手册的 0.30 焊盘 + 0.45/0.20 通孔放在球间位：焊盘边到过孔边 0.4596 − 0.15 − 0.225 = 0.085，低于 0.09。ST 板能放是因为它的焊盘只有 0.25（0.110）。[推导]

### 4.2 嘉立创能做什么

[原文：[PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities)，[HDI FAQ](https://jlcpcb.com/help/article/hdi-pcb-capabilities-faq)]

- 过孔最小 0.15 / 0.25 mm。**0.1 或 0.15 mm 的孔，以及 0.2 或 0.25 mm 的孔配小于 0.45 mm 的过孔外径，都"will cost more. Please select corresponding via size option when placing order."** 优选孔径 0.2。
- 盘中孔（环氧树脂填充并镀平）"is the default for 6-layer and above multilayer boards"，适用孔径 0.15–0.55 mm；"Vias can be placed within BGA pads using filled and plated-over vias."
- "Plugged vias"（阻焊填充）要求和其他开窗至少隔 0.35 mm，所以不能用在狗骨头孔上（狗骨头孔离球开窗只有 0.12 mm）。
- HDI（激光盲孔）是另一套工艺：4–24 层，默认激光孔 0.1 mm，焊盘 ≥ 孔 + 0.15，盲孔到其他孔的边距同网 0.13 / 异网 0.24，介质 0.05–0.127 mm，线宽线距 3/3 mil。HDI FAQ 里的叠层示例是 8 层的 `JLCH081611Y2-1078A`，没提 JLC06161H-3313E。

### 4.3 建议

**球间狗骨头，0.30 / 0.15 mm，不在球焊盘上打孔。** 过孔 0.30 / 0.15 是规格档 C 已有的值；新信息是嘉立创对这个孔径要多收费，要在下单时选过孔选项，用户要知道。

两个替代都不建议：

| 方案 | 为什么不选 |
|---|---|
| 通孔 0.45 / 0.20（嘉立创标准价） | 要焊盘 ≤ 0.28 才放得进四球中间；相邻两个球间位的孔，孔到线只有 0.18，一根线都过不去。ST 板这么用的前提是焊盘只有 0.25，而且信号孔大多是激光盲孔 |
| HDI 激光盲孔（ST 的做法） | 嘉立创有工艺，但叠层、价格、是否接受 3313E 类叠层都没核实；等于改叠层，不在规格档 C 里，要用户批准（RUL-5） |

盘中孔在这个封装上不需要：每个球都有 4 个球间位可用，环 4 的 24 个空位也能放孔。规格档 C 的"出不来的内圈球要用户批准盘中孔"这条在 UFBGA176+25 上不会触发。

## 五、几圈球要几层信号层

### 5.1 出线容量的算法

下面是计数，不是布线结果。[推导]

几何：焊盘 0.30、球距 0.65 时，相邻两焊盘之间的空隙 0.35 mm，放得下一根 0.09 线加两边 0.09 间距（0.27）。所以一个环上每个"球间缝"同一层只能通过一根线。

- 环 0 有 56 个球，就有 56 个球间缝。环 1 的 48 个球每个要占一个缝（线从环 1 球斜 45° 走到球间位，再垂直穿过缝），剩 8 个缝。环 2 最多再有 8 个球能走顶层。ST 板的环 2 里有 5 个球就是这样走的，吻合。
- 所以顶层能出：环 0 + 环 1（104 球）+ 环 2 的至多 8 个。
- 再往里要过孔。球间位按层级数：层级 0 在环 0 和环 1 之间（52 个位），层级 1 在环 1 和环 2 之间（44 个位），层级 2 在环 2 和环 3 之间（36 个位），层级 3 在环 3 和空圈之间（28 个位）。

### 5.2 方案

规格档 C 的叠层是 L1 信号 / L2 地 / L3 电源 / L4 信号 / L5 地 / L6 信号，所以内层可走信号的只有 L4，另外 L6。ST 的 H7 应用笔记给的六层叠层示例也是这个次序（顶层高速 + GND / GND / 电源 / 低速信号 / GND / 底层高速）[原文：[AN4938](https://www.st.com/resource/en/application_note/an4938-getting-started-with-stm32h74xig-and-stm32h75xig-mcu-hardware-development-stmicroelectronics.pdf) Rev 7 图 20，p.38/46]。

| 层 | 出哪几圈 | 数量 |
|---|---|---|
| L1 | 环 0、环 1，加环 2 的至多 8 个 | 97 个信号球直出（另有 7 个电源地球打孔） |
| L4 | 环 2、环 3 的信号球：狗骨头通孔，通孔放在环 2 外侧球间位（层级 1）和环 3 外侧球间位（层级 2）或内侧（层级 3） | 最多 46 个，每边环 2 最多 8 个、环 3 最多 6 个 |
| L6 | 备用，背面去耦电容占着球阵正下方，只在电容空档出线 | |

这里有一点要提醒。环 2 的通孔放在层级 1 之后，环 3 的线从 L4 出来要穿过层级 1 的那一排孔。孔径 0.15、线宽 0.09 时，两个相邻球间位的孔之间能过线，但孔到线只有 0.205 mm，嘉立创要求 0.2，余量 0.005 mm，换句话说线要正好走在两孔中线上（±0.005 mm）。所以环 3 的线要穿过的是**旁边有空位的缝**（相邻球间位没放孔，缝宽 1.0 mm）。环 2 每边 6–8 个信号孔放在 10–11 个层级 1 位上，空位够用，但要在布局阶段摆好，这是 LAY-3 试走该验证的东西。

按规格档 B 里的经验说法"每个信号层再出一圈"，这里要 L1（环 0–1）+ L4（环 2）+ L6（环 3）三个信号层。上面的计数说两个够（L1 + L4），但余量小，所以**下限 2 个，保守 3 个**。ST 靠激光盲孔用了 4 个信号层。

### 5.3 引脚分配的含义

环 0–1 有 97 个信号球，六成引脚是 84 个。如果引脚分配把用到的信号尽量放在环 0–1，环 2–3 的负担会小很多。但 SDRAM 总线的 23 个固定引脚落在环 2–3（见 2.3），所以环 2–3 至少有这 23 个。引脚分配那一票要把这个数带上。

## 六、内圈电源球和地球

[推导，除非另注]

- **中心 25 个 VSS 球**：用球间位通孔把它们接到 L2 和 L5 的地平面。5 × 5 个球有 4 × 4 = 16 个球间位，每个位的孔用四条短线连到周围 4 个球；9 个孔就能让每个球至少碰到一个孔，ST 放满了 16 个 [实测]。孔径用 0.30 / 0.15。电源平面 L3 会在中心被打出一个约 2.5 × 2.5 mm 的孔洞（16 个孔占 1.95 mm 见方，再加每个孔的避让），这是电源铜皮草图（LAY-1）要考虑的。
- **环 4 的 24 个空位**：位置在球网格上，离相邻的环 3 球和中心块球各 0.65 mm，焊盘边距 0.35 mm。可以直接放孔，用短线接环 3 的地球和中心块。ST 板在空位里放了 3 个通孔 [实测]。
- **环 2、环 3 的电源球和环 3 的地球**（共 26 个）：球间位通孔，通孔在层级 2；同网络的相邻球（例如 C7、C8、C9 三个 VDD 并排）可以在顶层用一条铜皮连起来共用 1–2 个孔。
- **VCAP（F13、M10）**：每个球就近一个孔；电容值和个数由电源树那一票按数据手册定，这里只管孔位。

## 七、背面去耦电容

### 7.1 ST 的说法

AN4938 §9.3：[原文：AN4938 Rev 7，p.38–39/46，图 21、22；§7.4 图 17]

- "For BGA packages, it is recommended to place the decoupling capacitors on the other side of the PCB."
- "Connect the decoupling capacitor pad to the power and ground plane with a wider, short trace/via."
- 每组 VDD/VSS 用 100 nF 陶瓷电容 + 一个至少 4.7 µF 的电容并联，"as close as possible to, or below, the appropriate pins on the underside of the PCB"。

AN5419（H72x/H73x，Rev 3）有同样的话。

### 7.2 ST 板的实际做法

MB1520 C 版 U6 周围 6 mm 内：[实测]

- 顶面没有别的器件。背面有 14 个 0402 + 1 个 0603 + 1 个 0805 + 1 个磁珠，14 个 0402 全部在球阵外形（±4.85 mm）以内。
- 每个 0402 的两个焊盘：一个焊盘里直接打一个 0.1 mm 激光盲孔（L6→L5 平面，应是地，没有网表核实）；另一个焊盘用 0.58–0.73 mm 的短线连到旁边的 0.2 mm 通孔（14 个里 13 个是这样，另 1 个是 0.83 mm 到一个盲孔）。这个通孔应该就是电源球的狗骨头孔，同样没有网表核实。
- 0402 中心到最近电源球中心的平面距离：0.35–2.04 mm，中位数约 1.2 mm。（电源球的位置要先知道封装朝向：P&P 文件写转角 180°，我用"电源地球旁边有通孔"的得分选出同一个朝向；结果合理，离 VREF+、VDDA、VBAT、VCAP 球最近的各有一个电容，但没有网表可核对。）
- 这是 `layout.md` 里"去耦电容到电源脚的距离上限取多少"这个悬而未决的问题的一个数据点：ST 自己的板子，14 个 0402 到最近电源球的平面距离全部 ≤ 2.04 mm，一半 ≤ 1.2 mm。

### 7.3 用在标准六层上要改的

ST 的"焊盘里打盲孔"我们做不到（盲孔是 HDI）。规格档 C 的约定是"盘中孔只在 BGA 背面去耦电容的焊盘"，用嘉立创的盘中孔工艺（通孔填充镀平）可以做，但通孔会穿到顶层，落在球阵下面。[推导]

- 通孔必须落在顶面的球间位上，否则顶到球焊盘（正是 LAY-5 写的那个问题）。球间位在 0.65 mm 网格上，KiCad 的 C_0402 两个焊盘中心距 0.96 mm，对不上。
- 所以建议和 ST 的电源脚那一侧一样：**两个焊盘都用 0.6–0.7 mm 短线接旁边的球间位通孔**，一个是电源球的狗骨头孔，另一个是邻近 VSS 球的狗骨头孔。把电容摆在"VDD 球孔和 VSS 球孔相距约 1 mm"的位置上。
- 这个"约定"需要在布局阶段逐个电容定下来（LAY-5 的例外要有位置）。

## 八、SDRAM 一侧（90 球，0.8 mm）

### 8.1 Micron 的封装图

Micron 128Mb x32 SDR SDRAM（MT48LC4M32B2）数据手册 Rev V 03/16（文档号 09005aef80872800）图 5，90 球 VFBGA 8 × 13 mm：[原文]

- 球距 0.80 TYP，回流后球径 Ø0.45（回流前 Ø0.42，配 0.40 的 SMD 焊盘），高 ≤ 1.00。
- **"Recommended pad size for PCB is 0.33mm ±0.025mm."**
- 球阵：左 1–3 列、右 7–9 列，各 15 行；中间 4–6 列没有球。左右两组球心相距 3.20 mm。

Micron 官网的原链接已经 404；上面读的是第三方镜像（[chipsmall](https://datasheet.chipsmall.com/MT48LC4M32B2P-6-G/673525.pdf)）上的同一份 PDF，页脚写着 Micron 文档号和版本。这份是 128Mb 的，具体选哪颗 SDRAM 是另一张票，选定后要用那颗的数据手册重新核对焊盘。

KiCad 自带的 `BGA-90_8.0x13.0mm_Layout2x3x15_P0.8mm` 焊盘是 0.4 mm（来源是 ISSI 的 IS42S32800J），和 Micron 的 0.33 不同。[实测]

### 8.2 球分布

按 Micron 图 3 读出来的：90 球 = 56 信号 + 28 电源地（VDD 4、VDDQ 10、VSS 4、VSSQ 10）+ 6 个 NC/NU。

| 列 | 信号 | 电源地 | 去向 |
|---|---|---|---|
| 1（边） | 8 | 7 | 向外直出 |
| 2 | 12 | 2 | 穿过第 1 列球间缝向外出 |
| 3（靠中间） | 7 | 5 | 向中间空出的 3 列出 |
| 7（靠中间） | 8 | 5 | 向中间出 |
| 8 | 13 | 2 | 向外 |
| 9（边） | 8 | 7 | 向外直出 |

### 8.3 计算和方案 [推导]

焊盘 0.33、球距 0.8：

| 检查项 | 结果 |
|---|---|
| 两焊盘间空隙 | 0.47 mm |
| 过一根 0.09/0.09 线（0.27） | 余量 0.20 |
| 过一根 0.127/0.127 线（0.381） | 余量 0.089 |
| 过两根 0.09/0.09 线（0.45） | 余量 0.02（不建议） |
| 四球中间的狗骨头孔，0.30/0.15 | 焊盘边到孔边 0.251 |
| 同上，0.40/0.20（规格档 B 的 BGA 过孔） | 0.201 |
| 相邻球间位两个孔之间过 0.127 线，孔 0.15 | 孔到线 0.262（≥ 0.2），孔间余量 0.119 |

方案：

- **全部在顶层出线，不需要内层。** 第 1、9 列（边上）直接向外；第 2、8 列的信号从第 1、9 列球之间的缝穿出去（每根占一个缝，14 个缝够用）；第 3、7 列的 15 个信号球向中间空出的通道出，通道净宽约 2.87 mm，顶层可放 15 根线。
- 28 个电源地球用狗骨头孔：第 3、7 列的孔放在中间通道里；第 2、8 列只有 B、P 两行的电源球，放在第 2/3 列之间的球间位（这些位不被第 2 列的信号线占用）；第 1、9 列的孔放在封装外侧的球间位，但这些位正对第 2、8 列信号的出口缝，会堵住出口，所以同网络的相邻球（VSS 和 VSSQ 都接地，VDD 和 VDDQ 都接 3.3 V）在顶层连起来共用一个孔，孔位具体由试走定。
- 焊盘 0.33（Micron）；开窗 Ø0.43 [推导]：线到开窗边 0.14 mm，没有嘉立创 0.09 的问题。（ST 的 0.8 mm 球距 TFBGA240+25 用的是焊盘 0.40 / 开窗 0.47，AN4488 的 0.8 mm 例子用焊盘 0.4 / 开窗 0.5，都是单边扩 0.035–0.05。）
- 背面去耦：同 MCU，放在 SDRAM 正下方。数据手册没有给每个电源球要几个电容，ST 的 AN4938 只说了 MCU 一侧，所以电容数量要另外定。
- ST 的 AN4488（F4 的硬件指南，0.8 mm 的 TFBGA216 例子）也给过同样的原则：最外两行两列不用扇出过孔直接走线，"allows to route only one trace between two adjacent BGA land pads"，过孔 0.45 / 0.2、线 0.10 / 0.125。[原文：[AN4488](https://www.st.com/resource/en/application_note/an4488-getting-started-with-stm32f4xxxx-mcu-hardware-development-stmicroelectronics.pdf) Rev 7，§8.5.1，p.41–42/50]

### 8.4 和规格档 B 的差别

规格档 B（草稿）假设焊盘 0.4 mm，"要对器件规格书核实"。Micron 的实际是 0.33。重算：

| 检查项 | 档 B（焊盘 0.4） | 焊盘 0.33 |
|---|---|---|
| 两焊盘间过一根 0.127/0.127 线 | 余量 0.019 | 0.089 |
| 四球中间过孔（0.4/0.2）的焊盘边距 | 0.166 | 0.201 |

孔到线（0.2365）不变。结论：B 档的 0.4 / 0.2 过孔放得下；规格档 C 的 0.30 / 0.15 过孔放得更宽松。如果想让整块板两个 BGA 共用一套过孔规则（方便规则区），可以都用 C 档的值，这是个例外，要用户批准（RUL-5）。

## 九、和规格档 C 球距计算表的对照

规格档 C 的表：球距 0.65、焊盘 0.35、线 0.09/0.09、过孔 0.3/0.15、孔到铜 0.2。下面按 ST 数据手册的焊盘 0.30 重算，并多列一栏 ST 板的 0.25。[推导，用嘉立创下限]

| 检查项 | 规格档 C（焊盘 0.35） | 焊盘 0.30（ST 数据手册） | 焊盘 0.25（ST 板） | 下限 |
|---|---|---|---|---|
| 两个焊盘之间过一根线（0.09/0.09） | 空隙 0.30，余量 0.03 | 空隙 0.35，余量 **0.08** | 空隙 0.40，余量 0.13 | — |
| 四球中间放过孔 0.30/0.15（焊盘边到孔边） | 0.135 | **0.160** | 0.185 | 0.09 |
| 两个球间位过孔之间过一根线 | 空隙 0.35，余量 0.08 | 同 | 同 | — |
| 过孔的孔到那根线 | 0.205，余量 0.005 | **不变** | 不变 | 0.2 |
| 同样位置走 0.1016 的线 | 0.199 ✗ | 不变 | 不变 | 0.2 |
| **新增**：四球中间放 0.45/0.20 通孔 | 0.060 ✗（C 档焊盘） | 0.085 ✗（差 0.005） | 0.110 ✓ | 0.09 |
| **新增**：0.45/0.20 通孔相邻球间位之间的孔到线 | 0.18 ✗ | 0.18 ✗ | 0.18 ✗ | 0.2 |
| **新增**：线走在两焊盘中间，线边到阻焊开窗边（Dsm = 0.40 / 0.38） | — | 0.080 ✗ / 0.090 ✓ | 0.105（Dsm 0.35） | 0.09（嘉立创） |
| **新增**：环 1 要占的球间缝 / 环 0 有的缝 | — | 48 / 56 | 同 | — |

差异清单：

1. 焊盘：档 C 的 0.35 换成 0.30（UFBGA176+25）。余量变宽，但**最紧的一项（孔到线，0.005）不受焊盘影响**，仍然是这一档最要紧的地方。
2. 档 C 里写"芯片厂参考设计用的 0.4/0.2 过孔孔到线只剩 0.18，不能用"在这个封装上也成立；ST 自己的 H7 板用 0.45/0.20 通孔 + 0.25 焊盘 + 激光盲孔，不能照搬到标准六层上。
3. 加一行阻焊：开窗 ≤ 0.38。档 C 没有任何阻焊规则。
4. 嘉立创对 0.15 孔多收费，档 C 的"依据"栏只写了"过孔最小 0.25/0.15"，没写加价。
5. 档 C 写"盘中孔：…… 出不来的内圈球要用户批准"。这个封装不会出现，因为 24 个空位和球间位足够。
6. ST 的焊盘出线宽度是 0.10，档 C 是 0.09。焊盘之间过 0.10 线还有 0.05 余量，但在过孔之间 0.10 线的孔到线是 0.200，余量 0。所以 BGA 区内 0.09 是对的。

### 未核实

1. 嘉立创 0.15 孔具体加多少钱，下单时"过孔选项"怎么选。
2. 嘉立创"阻焊开窗到邻线 ≥ 0.09"是量开窗边还是焊盘边；"开窗 1:1"是不是指 CAM 不再加扩展。
3. 嘉立创 HDI 能不能用 6 层 1+4+1，叠层和报价；是否兼容 JLC06161H-3313E。
4. 大量通孔穿过 L2 / L3（球阵下约 70–80 个）对平面完整性的影响。
5. 是否要真的在 KiCad 里试走一次环 2–3 的 L4 出线（建议在布局阶段做，LAY-3）。
6. 数据手册没有明说 UFBGA176+25 推荐 NSMD；图 129 的几何是 NSMD，是我据此推的。
7. 嘉立创贴片对 0.65 mm 球距 BGA 的要求、钢网厚度（ST 写 0.10–0.125）、表面处理（ENIG 还是别的）。
8. SDRAM 具体型号还没选：Micron 的焊盘 0.33 来自 128Mb 的 MT48LC4M32B2；ISSI IS42S32800J 等的封装图没有读到（只读到管脚图，封装图在被截断的镜像里），Alliance、Winbond 的没看。
9. SDRAM 一侧每个电源球要几个电容：厂家数据手册没写。
10. husn 的 oshwhub 工程：页面只有文字，没有版图预览（"未生成预览图"），声称"四层全扇出 0.65 mm"，没给过孔尺寸，也不说封装；我无法验证，也没有从里面取任何东西。
11. 找不到别的公开的 UFBGA176+25 板版图：GitHub 上搜到的 H743IIK6/H750IBK6 工程只有原理图 PDF 或空仓库。ST 官方板之外没有其他版图证据。
12. MB1520 是 HDI 板，它的扇出做法能不能搬到标准叠层，我只能算，不能证。
13. 背面去耦的"两个焊盘都短线接球间位孔"是我的方案，ST 没这么做（ST 用盲孔）。

## 十一、和 `docs/shape/` 规则的摩擦

- **RUL-11**（"没有合适的就先新建一档交用户批准，不从低一档的数值改起"）：规格档 C 的计算表是按焊盘 0.35 写的，这个封装的真实值 0.30，ST 自己板用 0.25。是改 C 档还是给 UFBGA176+25 新开一档，要用户定。我没有改 `docs/rule-profiles/`。
- **RUL-5**（规则例外先问用户）：本文建议的 0.38 阻焊开窗、嘉立创 0.15 孔加价、背面电容的盘中孔（C 档已有约定）、两个 BGA 共用 C 档的过孔值，都是要用户批准的例外。
- **RUL-12**（先列球距计算表）：第九节就是这张表的输入，缺一项：焊盘数值要用器件规格书的，不能用假设值。
- **LAY-5**（背面器件不放在顶面焊盘的投影下，"约定的 BGA 背面去耦"除外）：这条里的"约定"现在可以写成具体的了——背面电容的孔必须落在顶面的球间位，两个焊盘各接一个狗骨头孔。
- **LAY-2 / LAY-3**（出线通道、试走）：第五节的容量计数可以当 LAY-2"每个球有没有出线通道"的验收口径；环 2–3 的 L4 出线要在布局阶段试走。
- **RTE-1**（线序当迭代问题）：FMC 引脚散在四边（2.3），线序和 SDRAM 的摆放位置要一起定。
- **RTE-4**（"0.5 mm 间距 IC 的扇出手工做"）：条文只管 0.5 mm。0.65 mm 球距的 BGA 扇出没有被覆盖，建议同样手工做。（AD 的 Fanout 命令能按规则自动打狗骨头孔；据我所知 KiCad 没有对应的内置命令，但没有在 KiCad 10 里核实。）
- **layout.md 的悬而未决问题**（去耦电容到电源脚的距离）：7.2 里的 ST 板数据点可以拿去参考。

- 球阵：用脚本读 KiCad 符号里 `STM32H743IIKx` 每个引脚的编号、名称、类型，和封装里 201 个圆焊盘的坐标对应；环号 = min(行, 列, 14−行, 14−列)；电源地按名称（VDD*、VCAP*、VBAT、VREF+、VSS*、VREF-）分类。
- MB1520 分析：解压 `MB1520C/Gerber` 里的 `.GTL .G1–.G4 .GBL`（RS-274X，4.3 格式，毫米）和三个钻孔文件（Excellon，4.3，LZ），P&P 文件给封装中心 (67.300, 61.175) mm。在 GTL 上找 Ø0.25 的 201 个圆焊盘，确认它们落在 0.65 mm 网格上。过孔位置 = 钻孔坐标；"球间位"= 偏离球网格 (0.325, 0.325) mm 的点，"盘中"= 距球心 < 0.12 mm。逐环归类是用几何位置推的，**没有网表**，所以"这个球用了这个孔"是几何近似。封装朝向用"电源球旁边有通孔"的得分和 P&P 的 180° 转角一起定。
- 计算：焊盘间空隙 = 球距 − 焊盘径；四球中心到球心 = 球距 / √2；孔到线 = 球距 / 2 − 孔径 / 2 − 线宽 / 2。
