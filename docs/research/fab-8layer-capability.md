对应票：GitHub issue #30（地图 #26「RK3568 + DDR3 核心块」的子票）。查阅日期：**2026-11-26**（除非另注）。
范围：8 层验证板（RK3568 BGA-636，0.65 mm 球距；两颗 DDR3 96 球，0.8 mm 球距）要用的叠层和工艺。主对象嘉立创（JLCPCB 国际站 + 嘉立创国内站），对比华秋（NextPCB 是华秋的海外站，推断见 §7）和 PCBWay。

## 0. 结论

1. **嘉立创 8 层可做，叠层有二十来种，但本次没能读到现行的 8 层叠层表。** 国际站 `/impedance` 的静态页面只有 4 层和 6 层的表，8 层的表在页面脚本里（没登录、没调后台接口，不绕开）。8 层的数据来自第三方对嘉立创接口的存档（2025-05），**那份存档里的 6 层叠层已经和现行页面对不上**（§1.3），所以 §1 的 8 层数据只能当“候选名单和结构”，**写进 `data/stackups/` 之前必须在嘉立创的阻抗计算器上逐项核对**。
2. **适合“信号层都紧邻参考面”的结构**：存档里内芯 0.1 mm、中间叠 7628+1080+7628 的 `JLC08161H-1080A`（外层 1 oz、内层 0.5 oz、1.6 mm）：L1–L2 0.076、L2–L3 0.1、L3–L4 0.505、L4–L5 0.1、L5–L6 0.505、L6–L7 0.1、L7–L8 0.076 mm。层序 信号 / 地 / 信号 / 电源 / 地 / 信号 / 地 / 信号，四个信号层各有一个 0.076–0.1 mm 的参考面。内层 1 oz 的同类结构有 `JLC081611-1080`、`-2116A`、`-2116B`、`-3313`、`-1080A`。
3. **细间距能力够用，没有新的硬缺口**：多层板线宽线距 0.09/0.09 mm（3.5 mil）、BGA 焊盘到线 0.09 mm、最小过孔 0.15/0.25 mm、6–20 层盘中孔（树脂/铜浆塞孔 + 电镀盖帽）免费。规格档 C 的数值在 8 层上全部仍然成立。
4. **新信息**：背钻（4–32 层、板厚 ≥ 0.8 mm）、盲埋孔/HDI（1–3 阶）嘉立创都有，价格没公布；8 层 0.65 mm BGA 用不到它们，除非要做更高速的接口。
5. **价格查不到**：嘉立创、PCBWay、华秋的报价页都是脚本页面，没下单就没有数字。能确认的只有交期（嘉立创 6–32 层生产 5 天、网站显示 8–9 天）和零散的促销价。第三方文章的价格已过时。**这一项要用户在报价页上点一次。**

### 1.3 现行页面读不到 8 层，存档也已过时

## 3. 0.65 mm 球距 BGA 的可行做法

以下是我按嘉立创公布的下限做的**推导**（不是嘉立创给的结论），焊盘直径取 0.30 或 0.35（RK3568 的实际焊盘直径没查，按规格书定，见 §5 末段）；c 是焊盘边到过孔外径边的间距。

| 问题 | 算式 | 结果 | 依据 |
|---|---|---|---|
| 两球之间过一根线 | 空隙 = 0.65 − 焊盘；要 0.09 + 2 × 0.09 = 0.27 | 焊盘 0.30 余 0.08；0.35 余 0.03；焊盘最大 0.38 | J1：0.09/0.09，焊盘到线 0.09 |
| 狗骨头过孔最大外径（四球中间） | 0.65 × √2 − 焊盘 − 2c | 焊盘 0.30：c = 0.10 时 0.419，c = 0.09 时 0.439；焊盘 0.35：0.369 / 0.389 | J2 过孔铜到 BGA 焊盘 ≥ 0.10 |
| 外层过孔之间还要过一根线时的最大孔径 | 孔边到线 ≥ 0.2；半距 0.325 − 线半宽 0.045 − 0.2 = 0.08 → 孔径 ≤ 0.16 | **只能 0.15 孔** | J1 过孔孔到走线 0.2 |
| 同上，内层 | 内层过孔孔到铜 0.2，同样 ≤ 0.16；内层过孔不带盘时只有孔的限制 | 同上 | J1 + J2 |
| 不在过孔间过线时 | 0.2 孔 / 0.35–0.40 外径 | 放得下，**但 0.2 孔外径 < 0.45 要加价** | J1 |
| 盘中孔是否必须 | 球间过线通道和狗骨头通道都有，0.15 孔的狗骨头够用；**不必须** | 嘉立创 8 层盘中孔免费，所以球焊盘上打孔是可选项（项目自己限制了“球焊盘上不打孔”） | J1、J2、D4 |

要点：
- 0.65 mm 球距上，出线必须 0.09 的线，过孔 0.30/0.15（0.15 孔加价，金额未知）；换成 0.45/0.2 的过孔放不下（0.45 > 0.419）。这和规格档 C 现有结论一致。
- 孔边到线 0.2 的下限用 0.15 孔余量只有 0.005 mm（规格档 C 已记，钻孔位置公差 ±0.075 大于它），8 层上没有变化。
- 如果某个球的位置要用 0.2 孔，改用盘中孔（树脂塞孔，焊盘 ≥ 0.35 外径的疑问见 §2）。
- DDR3 0.8 mm 球距：空隙 0.8 − 焊盘（0.4–0.5 左右，规格书为准）= 0.3–0.4，过一根线（0.27）够，过两根线要 0.45，仅焊盘 ≤ 0.35 时可行；狗骨头 0.45/0.2 在 0.8 球距上放得下（c ≥ 0.1 时最大外径 ≈ 1.13 − 焊盘 − 0.2）。

## 5. 和规格档 C 的差别（要改的列在最后）

规格档 C 是六层档。逐项对 8 层：

| 规格档 C 现状 | 8 层调研结果 | 要不要改 |
|---|---|---|
| 区内线宽 0.09 / 间距 0.09；区外 0.1016 / 0.127 | 嘉立创下限 0.09/0.09（J1），< 0.0889 加收 20%（J4） | 不改 |
| 过孔区内 0.30/0.15，区外 0.45/0.2 起；0.15 孔加价金额没查到 | 仍然没有金额（J1、J4、D1）；“0.2 孔外径 < 0.45 也加价”（J1）与“0.45/0.2 起”不加价一致 | 不改；“金额没查到”继续 |
| 焊盘到过孔 0.10（嘉立创公布值） | J2 过孔铜到 BGA 焊盘 ≥ 0.10（原表是 2/4 层油墨塞孔） | 不改；8 层填孔的值没公布 |
| 孔到铜：过孔 0.2；插件孔 0.28 / 0.3；孔边到孔边 0.45 | J1 一致 | 不改 |
| BGA 阻焊扩展 0（嘉立创“开窗 1:1，开窗到邻线至少 0.09”） | J1 一致（2025-06 LDI 升级后 1:1） | 不改 |

| 叠层行：JLC06161H-3313E，“默认 3313 中间两层只隔 0.11；3313E 中间是 1.12” | 8 层要换：候选见 §1.4，推荐 `JLC08161H-1080A` 一类（待核对） | **新增 8 层叠层行**，等 §1.3 的核对 |

## 6. 不确定和互相矛盾的地方

1. **现行 8 层叠层表没读到**，§1.4 来自 2025-05 的第三方存档，6 层对比显示它已有漂移（§1.3）。
2. 国际站盘中孔焊盘要求“外径 ≥ 0.35”与同页示例“0.15/0.25”矛盾（J2）；对 0.65 mm 球距、焊盘 0.30 的球，盘中孔是否可行取决于这一条。
3. J3 的塞孔平整度“127 µm 凹陷、50 µm 凸起”看起来单位有误（应当是微米级），原文如此，没改。
4. “0.15–0.55 mm”是孔径还是外径，原文没说。
5. 小孔加价、背钻、盲埋孔、铜浆塞孔、阻抗测试的金额都没查到；J4 的小孔表和小板附加费在图片里。
6. 国内站和国际站阻焊参数不同（C1、C3：1.0 mil 与 1.2 mil），算阻抗用哪个要和下单站一致；国内站 8 层叠层表没读到。
7. 国际站 J1 页面没有页面日期；叠层页 J5 无日期。
8. 价格全部缺失（§4），捷配没能读到任何内容；华秋的工艺能力页没找到（只读到首页和 NextPCB 的能力页）。
9. 嘉立创的钻孔位置公差 ±0.075 > 孔到线余量 0.005（规格档 C 已记），8 层上也一样。

### 结论

没有哪家明显更合适：嘉立创在 0.09 mm 常规线宽、免费盘中孔、交期和价格（量级）上占优；华秋/NextPCB 的纸面线宽更细、有背钻和 HDI，但没有价格；PCBWay 线宽更松。**建议继续用嘉立创，8 层叠层以计算器核对结果为准。** 如果后面要做 PCIe 或 USB3 的背钻、或盲孔，要再向嘉立创和华秋各询一次价。

## 8. 给下一步的清单

1. 用户在嘉立创报价页（或阻抗计算器）里给出 8 层 1.6 mm 的叠层列表和报价（§1.3、§4），其中包括 `JLC08161H-1080A` 和默认叠层的价差。

4. 向嘉立创客服确认（可放进下单备注）：盘中孔焊盘外径 0.30 是否可做；0.15 孔加价金额；内层 0.5 oz 的 `1080A` 是否加价。
