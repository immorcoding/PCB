# 规格档 C：0.65 mm 及以下球距 BGA

适用：带 0.65 mm 球距 BGA（UFBGA、FCBGA 一类的应用处理器）的板子，六层起。0.5 mm 及以下球距没有做过，用之前先按同样的方法重算。

状态：**规则在一块板上验证过生效（金丝雀通过），但那块板没有做完**（六层 RK3568 板，已废弃，留档在分支 `integration-rk3568`）。2026-11-16 为 STM32H7 测试板按规格书焊盘重算并补了例外（[决定票](https://github.com/immorcoding/PCB/issues/10)），这块板 2026-11-20 起了工程：没有模板文件，工程文件由 `stm32h743_sdram/make_project.py` 从 `templates/common/` 加本档的数值生成，规则文件 `stm32h743_sdram/stm32h743_sdram.kicad_dru` 是本档目前唯一的实例；每条规则的行为由 `stm32h743_sdram/rules_fixture.py` 的基准板验证（69 个用例）。

## 球距计算表

焊盘直径是输入，**每个封装按规格书的值各列一张**，不沿用别的封装的表。区内取值：线 0.09、间距 0.09、过孔 0.30 / 0.15（mm，下同）。

### UFBGA176+25（STM32H743IIK6），球距 0.65，焊盘 0.30

焊盘取自 DS12110 表 217（Dpad 0.30）。

| 检查项 | 算式 | 结果 | 下限 |
|---|---|---|---|
| 两个焊盘之间过一根线 | 空隙 0.35；0.09 + 2 × 0.09 = 0.27 | 余量 0.08 | — |
| 四个球中间放过孔（焊盘到过孔） | 0.460 − 0.15 − 0.15 | 0.160 | 间距 0.09；嘉立创 0.10 |
| 过孔的孔到焊盘 | 0.460 − 0.15 − 0.075 | 0.235 | 孔到铜 0.2 |
| 两个过孔之间过一根线 | 空隙 0.35；0.27 | 余量 0.08 | — |
| 过孔的孔到那根线 | 0.325 − 0.075 − 0.045 | 0.205 | 孔到铜 0.2，**只有 0.005 余量** |
| 出区后换区外值 | 每 0.65 出两根线，线距 0.325；区外要 0.1016 + 0.127 = 0.229 | 余量 0.096 | — |
| 阻焊开窗边到邻线（扩展 0） | (0.65 − 0.30 − 0.09) / 2 | 0.13 | 嘉立创 0.09 |

不能用的组合：0.45 / 0.20 过孔放四球中间，焊盘到过孔只有 0.085；0.2 的孔在过孔间过线时孔到线只有 0.18；阻焊开窗 0.40（ST 的典型值）时开窗边到邻线 0.08。

### 90 球 SDRAM（IS42S32800J），球距 0.8，焊盘 0.33

焊盘取自 Micron 同封装的封装图。ISSI 的规格书（Rev C，2025-02-25，第 59 页）只给球径 0.45 mm（0.40–0.50）和球距 0.8 mm，没有推荐焊盘，所以 0.33 仍是借用 Micron 的值（2026-11-20 核对）。

| 检查项 | 区外值（线 0.1016 / 间距 0.127，孔 0.45 / 0.2） | 区内值 |
|---|---|---|
| 两个焊盘之间过一根线（空隙 0.47） | 余量 0.114 | 余量 0.20 |
| 四个球中间放过孔（焊盘到过孔） | 0.176 | 0.251 |
| 两个过孔之间过一根线 | 空隙 0.35，要 0.356，**差 0.006** | 空隙 0.50，余量 0.23 |
| 过孔的孔到那根线 | 0.249 | 0.280 |

按区外值过孔之间过不了线，所以这颗 SDRAM 也画规则区，用和 MCU 相同的区内值。

### 历史：RK3568（废弃板），球距 0.65，焊盘 0.35

焊盘 0.35 是当时的假设值。两焊盘间过线余量 0.03，焊盘到过孔 0.135，过孔间过线余量 0.08，孔到线 0.205；同样位置走 0.1016 的线，孔到线 0.199，不满足。

三张表共同的结论：BGA 区域里的线只能是 0.09，区外常用的 0.1016 线进了区域就违规；芯片厂参考设计用的 0.4 / 0.2 过孔不能用。孔到线的 0.005 余量只对名义尺寸成立（嘉立创钻孔位置公差 ±0.075，线宽公差 ±20%），过孔之间的线要正好居中。

## 规则区的写法

布局时在每个 BGA 外画一个规则区（AD 的 Room），不勾任何禁布项，所有层生效；`.kicad_dru` 里用 `A.intersectsArea('<名字>')` 判断，名字不支持通配符，逐个写。

**间距规则要排除铺铜区。** `A.intersectsArea()` 对铺铜区是按整块判断的：一块铺铜只要盖到规则区，全板都按区内的 0.09 mm 填充。间距规则的条件写成：

```
(rule "bga_clearance"
  (condition "A.Type != 'Zone' && B.Type != 'Zone' && (A.intersectsArea('BGA_MCU') || A.intersectsArea('BGA_SDRAM'))")
  (constraint clearance (min 0.09mm)))
```

2026-11-16 在 H7 的铜皮原型上实测（[原型票](https://github.com/immorcoding/PCB/issues/16)）：没有这两个 `Type` 条件时，整层铺地到局部铜皮是 0.092 mm（铺铜区设的是 0.20），L3 上两块电源之间是 0.092 mm（设的是 0.127）；加上之后是 0.201 mm 和 0.128 mm，规则金丝雀仍然输出 OK。废弃的 RK3568 板的规则文件用的是没有条件的写法。区内线宽和过孔的规则本来就带 `A.Type == 'Track'`、`A.Type == 'Via'`，不受影响。

小过孔的规则用 `A.enclosedByArea()`，不用 `intersectsArea()`：压在规则区边上的过孔按区外值查（2026-11-20 在基准板上实测）。

规则区的范围按板定，写在下面"各板批准的例外"里，扩大要重新找用户批准（RUL-5）。区外不放小过孔：去耦过孔在区外按 0.45 / 0.2 放不下，就回去改布局，不扩区。

区内外线宽的切换（用户 2026-11-18 定）：区内信号线 0.09，脚本在出区边 0.3 mm 处变回网络类的线宽，不等到第一个拐点（等到拐点会让 0.09 的线在区外留 2–4 mm，DRC 不报，那段也放不了蛇形）。线宽由三条规则检查，后面的优先：

- 通用：最小 0.1016。
- 碰到规则区但没完全在区内（`A.intersectsArea`）：最小 0.09。
- 完全在区内（`A.enclosedByArea`）：最小、最大都是 0.09。

DRC 逐段判线宽，换宽点要在区边外至少半个线宽。过孔由脚本按过孔坐标是否在区内选：区内用批准的例外值，区外用本档的常规过孔。

## 各板批准的例外

### STM32H7 测试板（用户 2026-11-16 批准）

| 例外 | 取值 | 原因 |
|---|---|---|
| 区内线宽和间距 | 0.09 / 0.09 | 0.65 球距两焊盘间只有 0.35 空隙 |
| 区内过孔 | 0.30 / 0.15，接受 0.15 孔加价 | 换 0.2 的孔，孔到线只有 0.18；没有不加价的替代 |
| SDRAM 也画规则区 | 和 MCU 相同的区内值 | 按区外值过孔间过不了线（差 0.006）；全板只留一种小过孔 |
| 规则区范围 | 封装外形每边外扩 1 mm（MCU 是 12 × 12 mm） | 狗骨头过孔全在球阵内，出区时线距 0.325 已满足区外值 |
| 盘中孔 | 只在区内背面去耦电容的焊盘上，过孔在球间位 | 电容在球阵正下方，0402 焊盘必然压到球间位的过孔 |
| BGA 焊盘阻焊扩展 | 0 | 照嘉立创的写法；开窗 0.38 时到邻线零余量 |
| 晶振 | 不加区内例外 | HSE 的球 G1 / H1 在最外圈，0.254 的线从焊盘直接向外出 |

这块板的未核对项：孔到线余量 0.005 只对名义尺寸成立；嘉立创"开窗 1:1"是否指板厂自己再补偿（下单时问客服）；0.15 孔的加价金额；ISSI 的焊盘推荐值；LSE 的球（PC14 / PC15）是否在最外圈，不在就要回来补例外。

## 还没解决的事

- 区内外两套线宽和过孔，走线工具怎么按位置切换（约定见上，实现没定）。
- “球焊盘上不打孔”和 BGA 焊盘阻焊扩展 0 还没有写成规则：等两颗 BGA 摆上板（有了位号）再加。
- 球距或脚距小于 0.65 mm 的器件（0.4 mm WLCSP、0.5 mm eMMC 一类）：进器件清单之前先列它自己的计算表、找用户批例外。
- 出线容量只是计数，没有在 KiCad 里试走过；球阵下几十个通孔对 L2 / L3 平面完整性的影响没评估。
