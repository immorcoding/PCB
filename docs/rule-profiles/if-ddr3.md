# 接口档：DDR3 / DDR3L

跟着接口走的起点值，和球距无关；规格档（A / B / C）管球距和工艺。做法在 `docs/shape/`（主要是 [走线 · high-speed](../shape/routing.high-speed.md)、RTE-5、RTE-11、RTE-19、LAY-11、PWR-5），每块板的取值写进它的 `SPEC.md` 第 7.2 节。

状态：**还没有在板上验证**。数值 2026-11-26 在[高速规则票](https://github.com/immorcoding/PCB/issues/43)上定，等长窗口在[时序预算票](https://github.com/immorcoding/PCB/issues/35)上定，对象是 RK3568 + 两颗 16 位 DDR3L（T 型，DDR3L-1600）。2026-11-27 补了包地的画法（[包地原型票](https://github.com/immorcoding/PCB/issues/47)）、差分对的起点值（[差分对原型票](https://github.com/immorcoding/PCB/issues/37)、[差分对工具票](https://github.com/immorcoding/PCB/issues/36)）和位交换的口径（[换位规则调研](https://github.com/immorcoding/PCB/issues/51)）。

取值的顺序（PROC-16）：瑞芯微的设计指南和官方参考板 → 板厂能力 → 本板实测 → 其他厂商的应用笔记。换芯片厂时整张表按那一家的指南重定。

出处的写法：HDG 是《RK3568 硬件设计指南》，HS 是瑞芯微的高速设计指南，CHK 是审查清单的 `DRAM` 工作表；页码和原文摘录在分支 `research/rk3568-ddr3-layout-requirements` 的 `docs/research/rk3568-ddr3-layout-requirements.md`。其他厂商的说法在分支 `research/highspeed-pcb-pitfalls` 的 `docs/research/highspeed-pcb-pitfalls.md`。

## 阻抗、线距、包地

| 项目 | 取值 | 出处 |
|---|---|---|
| 阻抗 | 单端 50 Ω ±10%，差分 100 Ω ±10% | HS 第 32–34 页；CHK 项 24 |
| 线距的口径 | 线宽的倍数，按边到边算 | 用户 2026-11-26 定（较严的读法） |
| DQ 之间、DQ 与 DM、字节组之间、地址命令之间 | ≥ 2 倍线宽 | HDG 第 179–181 页；HS 第 32–34 页 |
| DQ / DM 与 DQS、CLK 与其他所有线 | ≥ 3 倍线宽 | HDG 第 179、180 页（HS 写“建议 3 倍，至少 2 倍”） |
| 蛇形腿间距 | 数据、地址边到边 2 倍线宽；CLK、DQS 3 倍 | 用户 2026-11-26 定，沿用上面的倍数；瑞芯微没有单独给 |
| BGA 规则区内 | 豁免，每根线报收窄段的长度 | 各家都允许出线区放松 |
| 表层包地 | DQS、CLK 全程包地；DQ / DM 走 G-S-S-G（S-S ≥ 2 倍线宽，G-S 1 倍线宽）；地线每 200 mil（5.08 mm）内有地过孔。默认照做 | HDG 第 179、180 页；CHK 项 41、45 |
| 表层包地的画法 | 默认宽地线：一对里两根 DQ 相距 0.30 mm，隔着地的两根信号相距 0.70 mm（地铜 0.40 mm，放 0.4 / 0.2 过孔，线到过孔盘 0.15）；DQS 对两侧都是 0.70 的间隙，DM 单独一格（G-S-G）。地铜优先由 L1 / L6 的 GND 铺铜形成（铺铜到信号 0.15 mm），铺铜到不了的地方画同样宽度的 GND 走线。地过孔由脚本打在每条铜条上，间隔 ≤ 2.54 mm（上限 5.08 mm），在铺铜之前打。从相邻两根信号展开到 0.70 的位置开始包，可以在规则区内，球区内不铺；两头不包地的一段逐根报长度。窄地线（0.15 mm、间隙 0.45 mm、中间不打孔）不是走线时自选的画法：先修订 SPEC、用户同意后再用。本板取值写进 SPEC 第 7.2 节 | 用户 2026-11-27 定（[包地原型票](https://github.com/immorcoding/PCB/issues/47)）；官方板是 4 mil 的 GND 走线、过孔间隔中位 2.45 mm |

## 差分对

起点值，对象是 RK3568 的 DQS × 4 和 CLK（外层差分 0.104 / 0.15 mm）。做法见 RTE-16；工具的接口和指标表在[差分对工具票](https://github.com/immorcoding/PCB/issues/36)。

| 项目 | 取值 | 出处 |
|---|---|---|
| 网络名 | `<基名>_P` / `<基名>_N`（KiCad 只认这类后缀）；一对只找到一根时规则生成器报错 | [差分对工具票](https://github.com/immorcoding/PCB/issues/36) |
| 出 SoC 球区 | 内圈球的线 45° 拐进通道中心后直出，走另一侧是地球的那条通道；外圈球的线在盘内偏心 0.071 mm 出盘，一出盘就按 0.15 间隙并行 | 官方板 11 对都是这个画法；[差分对原型票](https://github.com/immorcoding/PCB/issues/37) |
| 同一对两个换层过孔的中心距 | 0.60–0.80 mm，默认 0.60（盘边到盘边 0.20）；“换层过孔中心距 ≥ 0.8”的例外，和别的信号过孔之间仍 ≥ 0.8 | 官方板 0.552；0.60 是嘉立创盘边到盘边的下限 |
| 换层的地过孔 | 不另加，借包地铜条上的过孔：两个，放在信号过孔来线一侧，离信号过孔中心 0.60 mm | [差分对原型票](https://github.com/immorcoding/PCB/issues/37) |
| 对内补偿（小耳朵） | 圆角矩形，画在短的那根上、向外凸；高度上限 0.20 mm，同一对等高，取能补完的最少个数、高度按要补的量反算；圆角半径 = 高度的一半；同一个耳朵的两条腿之间、相邻耳朵的腿之间边到边 ≥ 3 倍线宽（0.312 mm）；从 SoC 规则区内的展开段排起，排不下的顺着伸到规则区外的直线段 | 用户 2026-11-27 定（[差分对原型票](https://github.com/immorcoding/PCB/issues/37)） |
| 整对一起绕 | 和普通线同一个圆弧蛇形（RTE-7；P、N 同心圆弧）：腿中心距 0.81 mm（相邻两腿对的外边到外边 0.45 = 3 倍线宽），摆幅起点 0.81、上限 3.0 mm，块两头各 0.7 mm 直线；弯顶到别的信号 ≥ 0.45 mm | 用户 2026-11-27 定；3.0 是我取的数 |
| 间隙规则 | KiCad 的 `diff_pair_gap` 不写上限（顶边是直线的凸起一律报间隙越界）；并行段间隙恒定由工具查，耳朵、出球段、过孔段按清单放行 | [DRC 实验票](https://github.com/immorcoding/PCB/issues/44)；[差分对工具票](https://github.com/immorcoding/PCB/issues/36) |
| 非耦合长度预算 | 瑞芯微没给。扇出后量出各对的预测值，取最大值加 10% 写进 SPEC；用来拦变差，不是电气上限 | [差分对工具票](https://github.com/immorcoding/PCB/issues/36) |
| 包地 | 弯的一侧地铜窄于 0.30 mm 时铺铜进不去，这一段单侧没有包地，逐处报长度；包地不跟着绕 | 官方板的做法 |

## 参考面和过孔

| 项目 | 取值 | 出处 |
|---|---|---|
| 参考面 | 整层地；不跨分割 | HDG 第 177、178 页；CHK 项 63、65、66 |
| 离参考面边缘 | ≥ 40 mil（1.0 mm） | HDG 第 177 页；CHK 项 64（HS 第 28 页写 12 mil，取严的） |
| 换层地过孔 | 离信号过孔中心 ≤ 25 mil（0.635 mm） | HS 第 23 页；CHK 项 67（HDG 写 30 mil，取严的） |
| 球区外换层过孔的间距 | 避让圈之间留铜；数值按本板的过孔和避让圈算，写进 SPEC（瑞芯微模板用 0.2 / 0.4 的过孔时是 ≥ 0.7 mm） | HDG 第 177 页；LP4X 模板说明（旁证） |
| 过孔数 | 数据、DM、DQS ≤ 2；地址、控制、CLK ≤ 3，做得到 2 就按 2；同组个数和层序相同 | 瑞芯微的 ≤ 2 只写在 3200 Mbps 一段（HDG 第 178 页）；TI SPRABI1D §6.3.1.6 |
| 过孔残桩 | 通孔板不处理、不仿真 | 官方 6 层参考板同样是全通孔、内层走 DDR；TI SPRABI1D：标准速率不要求背钻。HS 第 10 页的“超过 12 mil 要仿真”记为未核对项 |
| 电源和地的球 | 每球一个过孔；正交相邻的同网络球在顶层连成“井”字，两侧过孔同网络时线宽 10 mil（0.254 mm），否则用规则区内的线宽 | HDG 第 172、175 页；宽度的取法是按 0.65 mm 球距、0.30 / 0.15 过孔算的，焊盘直径核对后重算 |

## 等长

窗口每组两个数，按工作目标判（RTE-19）。长度含 SoC 封装内引线（`RK3568_Package_PinLength_V1.0`，Draft）和过孔，颗粒一侧不计。

| 组 | 电气上限（瑞芯微） | 工作目标 |
|---|---|---|
| DQ、DM 对本字节 DQS（对的平均） | ±600 mil | ±50 mil（1.27 mm） |
| DQS 对内、CLK 对内 | 12 mil | 6 mil（0.15 mm） |
| DQS 对同一颗粒的 CLK | ±1500 mil | 不取紧 |
| CSn、CKE、ODT 对 CLK（每颗粒一条路径） | ±30 mil | ±20 mil（0.5 mm） |
| 其余地址命令对 CLK（每颗粒一条路径） | ±600 mil | ±200 mil（5.08 mm） |
| T 型两分支互差 | 20 mil | 10 mil（0.25 mm） |
| T 型分支长度 | 各 ≤ 600 mil | 尽量短，报长度 |

不设硬要求：方向（T 型按瑞芯微只限 DQS 和 CLK 的差值；fly-by 加写均衡才要求 CLK 不短于 DQS，换拓扑时重定）、总长上限（只报）、字节组之间的等长。

## 未核对项

- 过孔残桩没有仿真。
- “井”字连线让球焊盘的散热和上锡略不均匀，没有依据说要紧或不要紧；官方板是这样做的。
- 线距按边到边读是我们取严的读法，瑞芯微原文没有写明。
- 蛇形和补线区里的包地间隙没有定（官方板没有例子），普通线蛇形的腿间距要不要也改成 3 倍线宽没有定：都在 [RK3568 验证方案的地图](https://github.com/immorcoding/PCB/issues/26)的未定项里。
- 差分对的取值来自原型图，没有过 KiCad DRC，也没有在板上走过；`PAIRS` 的写法只有示意。
- 这一档的检查有六样还没有工具，见 [routing.md](../shape/routing.md) 的 Open questions。
